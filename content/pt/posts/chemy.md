## 1. O Que é a Alchemy?

A Alchemy é uma plataforma de infraestrutura blockchain que ajuda desenvolvedores a conectar suas aplicações a diferentes redes blockchain sem precisar criar e manter seus próprios nós.

Com a Alchemy, os desenvolvedores podem:

- Conectar-se a redes blockchain compatíveis.
- Acessar dados blockchain por meio de APIs RPC.
- Consultar informações de carteiras e transações.
- Obter dados relacionados a NFTs.
- Monitorar atividades e transações blockchain.
- Desenvolver e gerenciar aplicações Web3.

Para quem está começando, a Alchemy simplifica o desenvolvimento blockchain ao oferecer infraestrutura e serviços de API prontos para uso.

## 2. O Que Você Precisa Antes de Se Cadastrar na Alchemy?

Antes de criar uma conta na Alchemy, prepare os seguintes itens.

### Um Endereço de E-mail Válido

Você poderá precisar de um endereço de e-mail para se cadastrar, verificar sua conta ou receber notificações importantes de segurança.

Certifique-se de que consegue acessar esse endereço de e-mail durante todo o processo.

### Uma Conexão Estável com a Internet

A Alchemy é uma plataforma online. Você precisará de uma conexão com a Internet para acessar o site, o painel de controle e as ferramentas para desenvolvedores.

### Escolher uma Rede Blockchain

Se você já possui um projeto de desenvolvimento, determine a qual rede deseja se conectar.

Por exemplo:

- Ethereum Mainnet: a rede principal da Ethereum.
- Ethereum Sepolia: uma rede de testes da Ethereum.
- Base: uma rede blockchain baseada na tecnologia Ethereum.

Se você está começando no desenvolvimento blockchain, pode utilizar primeiro uma rede de testes para conhecer os recursos disponíveis.

## 3. Como Criar uma Conta na Alchemy

### Passo 1: Acesse o Site Oficial da Alchemy

Abra o site oficial da Alchemy:

[https://www.alchemy.com/](https://www.alchemy.com/)

Procure a opção Sign Up, Sign In ou Get Started.

Clique na opção de cadastro para começar a criar sua conta.

### Passo 2: Crie Sua Conta

Siga as instruções apresentadas na página de cadastro.

Dependendo das opções disponíveis, você poderá se cadastrar usando um endereço de e-mail ou um método de login de terceiros compatível.

Se escolher o cadastro por e-mail:

1. Informe seu endereço de e-mail.
2. Preencha as informações da conta solicitadas.
3. Siga as instruções para verificar seu e-mail ou concluir as verificações adicionais de segurança.
4. Faça login depois que o cadastro estiver concluído.

Os métodos de cadastro e os requisitos de verificação podem mudar. Siga sempre as instruções exibidas no site oficial da Alchemy.

### Passo 3: Acesse o Alchemy Dashboard

Depois de se cadastrar, acesse o painel de controle da Alchemy:

[https://dashboard.alchemy.com/](https://dashboard.alchemy.com/)

O Dashboard é o principal ambiente para gerenciar suas aplicações, API Keys, redes blockchain e configurações de serviços.

Se você for um novo usuário, a Alchemy poderá já ter criado uma aplicação padrão e uma API Key para sua conta.

Verifique primeiro as aplicações existentes antes de criar outra. Talvez seja possível utilizar diretamente a aplicação padrão.

## 4. Como Criar uma Aplicação na Alchemy

Uma aplicação da Alchemy conecta seu projeto às redes blockchain selecionadas e fornece as credenciais e os endpoints necessários para enviar solicitações.

Você pode criar aplicações separadas para diferentes projetos ou ambientes de desenvolvimento.

### Passo 1: Abra a Seção Apps

Faça login no Alchemy Dashboard.

Abra Team Overview no menu da sua equipe e selecione a aba Apps.

Procure a opção Create new app e clique nela.

### Passo 2: Preencha as Informações da Aplicação

A Alchemy solicitará que você configure sua nova aplicação.

As configurações disponíveis podem incluir:

App Name: Informe um nome para identificar seu projeto. Por exemplo, My Web3 Project.

Description: Adicione uma breve descrição da finalidade da aplicação. Esse campo pode ser opcional.

Chains: Selecione as redes blockchain às quais sua aplicação precisa ter acesso.

Services: Escolha os serviços necessários para seu projeto.

Se você estiver desenvolvendo uma aplicação Ethereum, selecione a rede Ethereum correspondente.

Se estiver apenas aprendendo ou realizando testes, considere utilizar primeiro uma rede de testes.

### Passo 3: Crie a Aplicação

Revise as configurações da sua aplicação.

Verifique se o nome, as redes selecionadas e os serviços habilitados estão corretos.

Clique em Create App para concluir o processo.

Depois que a aplicação for criada, a Alchemy abrirá a página de detalhes correspondente.

## 5. Como Obter Sua API Key da Alchemy

A API Key é utilizada para autenticar solicitações aos serviços da Alchemy associados à sua aplicação.

Siga as etapas abaixo para encontrá-la.

### Passo 1: Abra Sua Aplicação

Acesse a seção Apps no Alchemy Dashboard.

Localize a aplicação que acabou de criar e clique no nome para abrir a página de detalhes.

### Passo 2: Copie Sua API Key

Na página de detalhes da aplicação, localize a API Key, geralmente exibida na região superior direita.

Clique no botão de copiar para copiar a chave.

Guarde-a em um local seguro para utilizá-la no seu projeto de desenvolvimento.

Não publique sua API Key real em sites públicos, repositórios públicos do GitHub ou outros locais onde pessoas não autorizadas possam acessá-la.

### Passo 3: Encontre Seu API Endpoint

Depois de obter sua API Key, abra a aba Endpoints na página de detalhes da aplicação.

Nessa seção, você poderá consultar os endpoints HTTP e WebSocket das redes blockchain habilitadas.

Por exemplo, um endpoint HTTP RPC da Ethereum Mainnet geralmente segue este formato:

[https://eth-mainnet.g.alchemy.com/v2/YOUR_API_KEY](https://eth-mainnet.g.alchemy.com/v2/YOUR_API_KEY)

Substitua YOUR_API_KEY pela API Key copiada do Alchemy Dashboard.

Cada rede blockchain possui um endereço de endpoint diferente. Utilize sempre o endereço correspondente à rede selecionada.

## 6. Como Testar se Sua API Key da Alchemy Está Funcionando

Depois de obter sua API Key, é recomendável enviar uma solicitação simples para verificar se a configuração está correta.

Este exemplo utiliza a Ethereum Mainnet e o método JSON-RPC eth_blockNumber para consultar o número do bloco mais recente.

### Passo 1: Prepare Seu RPC Endpoint

Utilize o seguinte formato:

[https://eth-mainnet.g.alchemy.com/v2/YOUR_API_KEY](https://eth-mainnet.g.alchemy.com/v2/YOUR_API_KEY)

Substitua YOUR_API_KEY pela sua API Key real.

### Passo 2: Envie uma Solicitação Usando curl

Se o curl estiver disponível no seu computador, abra um terminal e execute o seguinte comando:

```
curl https://eth-mainnet.g.alchemy.com/v2/YOUR_API_KEY \
-X POST \
-H "Content-Type: application/json" \
-d '{"jsonrpc":"2.0","method":"eth_blockNumber","params":[],"id":1}'
```

Lembre-se de substituir YOUR_API_KEY pela sua chave real antes de executar o comando.

### Passo 3: Verifique a Resposta

Se a API Key e o endpoint estiverem configurados corretamente, você deverá receber uma resposta JSON semelhante a esta:

```
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": "0x..."
}
```

O campo result contém o número do bloco no formato hexadecimal.

Se a solicitação retornar um erro, verifique se a API Key está correta, se a rede correspondente está habilitada e se o formato da solicitação é válido.

## 7. Cuidados Importantes ao Utilizar a API Key da Alchemy

Sua API Key é uma credencial importante para acessar os serviços da Alchemy. Siga estas práticas de segurança para proteger sua conta e suas aplicações.

### Não Publique Sua API Key

Nunca exponha sua API Key real em repositórios públicos de código, fóruns online ou páginas acessíveis publicamente.

Para projetos de desenvolvimento, considere armazenar a chave em variáveis de ambiente ou arquivos de configuração seguros.

### Entenda a Diferença Entre API Keys e Access Keys

A Alchemy oferece diferentes tipos de credenciais para finalidades distintas.

Uma API Key de aplicação é normalmente utilizada para acessar endpoints RPC e APIs compatíveis associadas a uma aplicação.

As Access Keys são utilizadas em determinados cenários de autenticação e gerenciamento. Elas também podem oferecer controles adicionais de permissões.

Não presuma que essas credenciais sejam intercambiáveis. Consulte a documentação oficial da Alchemy antes de utilizá-las.

### Selecione a Rede Blockchain Correta

Certifique-se de que sua aplicação esteja configurada para a rede que você realmente pretende utilizar.

Por exemplo:

- Ethereum Mainnet é utilizada para a rede de produção da Ethereum.
- Ethereum Sepolia é utilizada para testes.
- Base é uma rede blockchain independente.

Utilizar um endpoint de uma rede incorreta pode causar resultados inesperados ou erros nas solicitações.

### Monitore o Uso e os Preços

A Alchemy oferece diferentes planos de utilização. Os recursos disponíveis, os limites e os preços podem mudar.

Antes de utilizar a Alchemy em uma aplicação de produção, consulte seu plano atual, os limites de utilização e as informações de cobrança no Dashboard.

Lembre-se também de que outros serviços relacionados a blockchain podem ter funções completamente diferentes. Por exemplo, a TRXAPI é focada no aluguel de energia TRON, enquanto a Alchemy oferece infraestrutura para desenvolvimento blockchain.

## 8. Perguntas Frequentes Sobre o Cadastro na Alchemy

### Q1: O Cadastro na Alchemy é Gratuito?

Criar uma conta e utilizar a plataforma são duas coisas diferentes.

A Alchemy oferece diferentes planos de utilização. Os recursos gratuitos, os limites de solicitações e os preços dependem do plano vigente.

Criar uma conta não significa necessariamente que todas as solicitações API e todos os serviços sejam gratuitos.

Consulte a página oficial de preços para obter as informações mais recentes:

[https://www.alchemy.com/pricing](https://www.alchemy.com/pricing)

### Q2: O Que Fazer se Eu Não Encontrar Minha API Key Após o Cadastro?

Primeiro, faça login no Alchemy Dashboard e abra a seção Apps.

Verifique se sua conta já possui uma aplicação padrão.

Se existir uma aplicação, abra a página de detalhes e procure a API Key.

Se nenhuma aplicação estiver disponível, selecione Create new app e conclua a configuração.

### Q3: Posso Criar Várias API Keys na Alchemy?

Você pode criar várias aplicações para diferentes projetos ou ambientes de desenvolvimento e gerenciar suas credenciais separadamente.

Por exemplo, pode utilizar aplicações diferentes para desenvolvimento, testes e produção.

Isso facilita a organização dos projetos e o monitoramento individual da utilização.

### Q4: Posso Compartilhar Minha API Key com Outros Desenvolvedores?

Não é recomendável compartilhá-la sem necessidade.

Se outros desenvolvedores precisarem acessar seus serviços da Alchemy, utilize as permissões de equipe e métodos seguros de gerenciamento de credenciais.

Não publique suas credenciais pessoais ou do projeto em locais públicos.

### Q5: Por Que Minha API Key da Alchemy Não Está Funcionando?

As causas mais comuns incluem:

1. A API Key foi copiada incorretamente.
2. O endpoint RPC está incorreto.
3. A rede blockchain necessária não está habilitada.
4. O método ou os parâmetros da solicitação são inválidos.
5. A aplicação possui restrições de utilização ou permissões.
6. Existe um problema de conexão com a Internet.

Verifique primeiro as configurações da aplicação e do endpoint. Você também pode consultar a documentação oficial da Alchemy para obter instruções de solução de problemas.
