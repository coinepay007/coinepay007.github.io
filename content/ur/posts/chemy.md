## 1. Alchemy کیا ہے؟

Alchemy ایک ایسا پلیٹ فارم ہے جو بلاک چین ایپلی کیشنز کی تیاری کے لیے انفراسٹرکچر سروسز فراہم کرتا ہے۔ ڈیولپرز Alchemy کے ذریعے بلاک چین نیٹ ورکس سے منسلک ہو سکتے ہیں، ڈیٹا حاصل کر سکتے ہیں اور Smart Contracts کے ساتھ تعامل کر سکتے ہیں۔

Alchemy کی اہم خصوصیات درج ذیل ہیں:

- **RPC سروسز:** ایپلی کیشنز اور بلاک چین نیٹ ورکس کے درمیان رابطہ قائم کرنے میں مدد دیتی ہیں۔
- **On-chain Data Access:** بلاک چین ٹرانزیکشنز، بلاکس اور دیگر ڈیٹا حاصل کرنے کی سہولت دیتی ہے۔
- **Developer Tools:** Web3 ایپلی کیشنز کی تیاری اور ڈیبگنگ میں مدد کرتے ہیں۔
- **API Services:** مختلف بلاک چین نیٹ ورکس سے منسلک ہونے کے لیے API فراہم کرتی ہیں۔

Alchemy استعمال کرنے کے لیے سب سے پہلے ایک اکاؤنٹ بنانا اور اپنے پروجیکٹ کے لیے API Key حاصل کرنا ضروری ہے۔

## 5. Alchemy API Key کیسے حاصل کریں؟

ایپ بنانے کے بعد آپ اس کی API Key دیکھ سکتے ہیں۔

### 5.1 ایپ کی تفصیلات کھولیں

Alchemy Dashboard میں Apps کی فہرست سے اپنی نئی بنائی گئی ایپ منتخب کریں۔

ایپ کی تفصیلات والے صفحے پر API سے متعلق معلومات دستیاب ہوں گی۔

### 5.2 API Key کاپی کریں

ایپ کی تفصیلات والے صفحے پر **API Key** کا آپشن تلاش کریں۔

کاپی کے بٹن پر کلک کرکے API Key کاپی کریں۔

API Key ایک تصدیقی معلومات ہے جسے آپ کی ایپلی کیشن Alchemy سروسز کو درخواستیں بھیجنے کے لیے استعمال کرتی ہے۔ اسے دوسروں کے سامنے ظاہر نہ کریں۔

### 5.3 Endpoints دیکھیں

ایپ کی تفصیلات والے صفحے پر **Endpoints** ٹیب میں مختلف نیٹ ورکس کے API Endpoints بھی دیکھے جا سکتے ہیں۔

Ethereum Mainnet RPC Endpoint کی مثال:

```
https://eth-mainnet.g.alchemy.com/v2/YOUR_API_KEY
```

یہاں `YOUR_API_KEY` کی جگہ اپنی اصل API Key درج کریں۔

یاد رکھیں کہ TRXAPI، TRON Energy Rental سے متعلق ایک الگ سروس ہے۔ اس کا Alchemy کے Ethereum RPC Endpoint سے کوئی تعلق نہیں ہے۔

## 6. API Key کے درست کام کرنے کی جانچ کریں

API Key کاپی کرنے کے بعد ایک API Request بھیج کر جانچ سکتے ہیں کہ آیا یہ درست طریقے سے کام کر رہی ہے یا نہیں۔

### 6.1 ٹیسٹ کمانڈ چلائیں

Terminal یا Command Line Tool کھولیں اور درج ذیل کمانڈ چلائیں۔

`YOUR_API_KEY` کی جگہ اپنی اصل API Key درج کریں۔

```
curl https://eth-mainnet.g.alchemy.com/v2/YOUR_API_KEY \
-X POST \
-H "Content-Type: application/json" \
-d '{"jsonrpc":"2.0","method":"eth_blockNumber","params":[],"id":1}'
```

### 6.2 جواب چیک کریں

اگر درخواست کامیابی سے مکمل ہو جائے تو آپ کو اس طرح کا JSON Response مل سکتا ہے:

```
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": "0x..."
}
```

اگر `result` فیلڈ میں بلاک نمبر ظاہر ہو تو اس کا مطلب ہے کہ API Request کامیابی سے پروسیس ہو گئی ہے۔

اگر کوئی خرابی ظاہر ہو تو API Key، Endpoint، نیٹ ورک سیٹنگز اور Request Format چیک کریں۔

## 7. Alchemy API Key استعمال کرتے وقت احتیاطی تدابیر

API Key حاصل کرنے کے بعد اسے محفوظ رکھنا بہت ضروری ہے۔

### 7.1 API Key کو عوامی نہ کریں

اپنی API Key کو عوامی GitHub Repository، پبلک دستاویزات یا Client-side Code میں براہ راست شامل نہ کریں۔

جہاں ممکن ہو، اسے محفوظ رکھنے کے لیے Environment Variables یا Server-side Settings استعمال کریں۔

### 7.2 API Key اور Access Key کا فرق سمجھیں

Alchemy، API Key کے علاوہ Access Key سے متعلق انتظامی سہولیات بھی فراہم کرتا ہے۔

دونوں کے استعمال اور انتظام کا طریقہ مختلف ہو سکتا ہے۔ اس لیے اپنے پروجیکٹ کی ضروریات کے مطابق درست Authentication طریقہ منتخب کرنے کے لیے آفیشل دستاویزات دیکھیں۔

### 7.3 درست نیٹ ورک Endpoint استعمال کریں

Ethereum Mainnet اور Ethereum Sepolia جیسے نیٹ ورکس کے Endpoints مختلف ہوتے ہیں۔

اس بات کا خیال رکھیں کہ Mainnet اور Testnet کو غلطی سے ایک دوسرے کی جگہ استعمال نہ کیا جائے۔

### 7.4 API کے استعمال اور اخراجات چیک کریں

اپنے Alchemy اکاؤنٹ کے استعمال اور فیس سے متعلق معلومات باقاعدگی سے چیک کریں۔

پروجیکٹ کے سائز کے مطابق API کا استعمال مختلف ہو سکتا ہے، اس لیے اپنے اکاؤنٹ پر لاگو قیمتوں اور استعمال کی حدود کے بارے میں معلومات حاصل کریں۔
