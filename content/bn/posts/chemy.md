# Alchemy রেজিস্ট্রেশন গাইড: কীভাবে অ্যাকাউন্ট তৈরি করবেন এবং API Key পাবেন

Alchemy হলো Web3 ডেভেলপারদের জন্য তৈরি একটি ব্লকচেইন অবকাঠামো প্ল্যাটফর্ম। এটি RPC পরিষেবা, অন-চেইন ডেটা অ্যাক্সেস এবং বিকেন্দ্রীভূত অ্যাপ্লিকেশন (DApp) তৈরিতে সহায়তা করে। এই গাইডে ধাপে ধাপে দেখানো হবে কীভাবে Alchemy অ্যাকাউন্ট তৈরি করবেন এবং API Key সংগ্রহ করবেন।

Web3 পরিষেবা ব্যবহারের সময় অনলাইন পেমেন্টের জন্য CoinePay-এর ভার্চুয়াল কার্ড পরিষেবা আলাদাভাবে বিবেচনা করতে পারেন। এছাড়া, TRON নেটওয়ার্কে লেনদেনের খরচ পরিচালনা করতে আগ্রহী ব্যবহারকারীরা TRXAPI-এর TRON Energy Rental পরিষেবা সম্পর্কেও জানতে পারেন। এই দুটি সম্পূর্ণ স্বতন্ত্র পরিষেবা; Alchemy-এর সঙ্গে এগুলোর কোনো আনুষ্ঠানিক অংশীদারত্ব বা ইন্টিগ্রেশন নেই।

## 1. Alchemy কী?

Alchemy হলো একটি ব্লকচেইন অবকাঠামো প্ল্যাটফর্ম, যা ব্লকচেইন অ্যাপ্লিকেশন তৈরির জন্য বিভিন্ন পরিষেবা প্রদান করে। ডেভেলপাররা Alchemy ব্যবহার করে ব্লকচেইন নেটওয়ার্কের সঙ্গে সংযোগ স্থাপন, ডেটা সংগ্রহ এবং Smart Contract-এর সঙ্গে ইন্টারঅ্যাক্ট করতে পারেন।

Alchemy-এর প্রধান সুবিধাগুলো হলো:

- **RPC পরিষেবা:** অ্যাপ্লিকেশন ও ব্লকচেইন নেটওয়ার্কের মধ্যে যোগাযোগ করতে সহায়তা করে।
- **On-chain Data Access:** ব্লকচেইনের ট্রানজ্যাকশন, ব্লক এবং অন্যান্য ডেটা সংগ্রহ করতে সাহায্য করে।
- **Developer Tools:** Web3 অ্যাপ্লিকেশন তৈরি ও ডিবাগ করতে সহায়তা করে।
- **API Services:** বিভিন্ন ব্লকচেইন নেটওয়ার্কের সঙ্গে সংযোগ স্থাপনের জন্য API প্রদান করে।

Alchemy ব্যবহার শুরু করতে প্রথমে একটি অ্যাকাউন্ট তৈরি করতে হবে এবং আপনার প্রজেক্টের জন্য একটি API Key সংগ্রহ করতে হবে।

## 2. Alchemy রেজিস্ট্রেশনের আগে যা প্রস্তুত রাখবেন

রেজিস্ট্রেশন শুরু করার আগে নিচের বিষয়গুলো প্রস্তুত রাখুন।

### 2.1 একটি কার্যকর ইমেইল ঠিকানা

Alchemy অ্যাকাউন্ট তৈরি এবং ইমেইল ভেরিফিকেশনের জন্য একটি সক্রিয় ইমেইল ঠিকানা প্রয়োজন।

### 2.2 স্থিতিশীল ইন্টারনেট সংযোগ

রেজিস্ট্রেশনের সময় ইমেইল ভেরিফিকেশন এবং Dashboard-এ লগইন করতে হবে। তাই স্থিতিশীল ইন্টারনেট সংযোগ ব্যবহার করুন।

### 2.3 কোন ব্লকচেইন নেটওয়ার্ক ব্যবহার করবেন তা নির্ধারণ করুন

API Key তৈরি করার আগে আপনি কোন ব্লকচেইন নেটওয়ার্ক ব্যবহার করবেন তা ঠিক করে নিন।

উদাহরণ:

- Ethereum Mainnet
- Ethereum Sepolia
- Base

অ্যাপ তৈরি করার সময় আপনার প্রয়োজন অনুযায়ী সঠিক নেটওয়ার্ক নির্বাচন করতে হবে।

## 3. Alchemy-এর অফিসিয়াল ওয়েবসাইটে অ্যাকাউন্ট তৈরি করুন

### 3.1 অফিসিয়াল ওয়েবসাইটে প্রবেশ করুন

Alchemy-এর অফিসিয়াল ওয়েবসাইটে যান।

[https://www.alchemy.com/](https://www.alchemy.com/)

হোমপেজে **Sign Up**, **Sign In** অথবা **Get Started** বাটনে ক্লিক করুন।

### 3.2 রেজিস্ট্রেশন সম্পন্ন করুন

স্ক্রিনে দেখানো নির্দেশনা অনুসরণ করুন। আপনি ইমেইল ঠিকানা দিয়ে অ্যাকাউন্ট তৈরি করতে পারেন অথবা সমর্থিত থার্ড-পার্টি লগইন পদ্ধতি ব্যবহার করতে পারেন।

ইমেইল দিয়ে রেজিস্ট্রেশন করলে নিচের ধাপগুলো অনুসরণ করুন:

1. আপনার ইমেইল ঠিকানা লিখুন।
2. পাসওয়ার্ড সেট করুন অথবা স্ক্রিনে দেখানো নির্দেশনা অনুসরণ করুন।
3. ইমেইল ইনবক্সে ভেরিফিকেশন মেসেজ খুঁজুন।
4. ইমেইল ভেরিফিকেশন সম্পন্ন করে অ্যাকাউন্টে লগইন করুন।

### 3.3 Dashboard-এ প্রবেশ করুন

লগইন সম্পন্ন হলে Alchemy Dashboard খুলুন।

[https://dashboard.alchemy.com/](https://dashboard.alchemy.com/)

Dashboard হলো Alchemy-এর প্রধান ইন্টারফেস, যেখানে আপনি অ্যাপ এবং API Key পরিচালনা করতে পারবেন।

কিছু অ্যাকাউন্টে রেজিস্ট্রেশনের পর থেকেই একটি ডিফল্ট অ্যাপ বা API Key দেখা যেতে পারে। প্রথমে উপলব্ধ তথ্য পরীক্ষা করুন এবং প্রয়োজন হলে নতুন অ্যাপ তৈরি করুন।

## 4. Alchemy-তে নতুন অ্যাপ তৈরি করুন

API Key সুশৃঙ্খলভাবে পরিচালনা করার জন্য প্রতিটি প্রজেক্টের জন্য আলাদা অ্যাপ তৈরি করা সুবিধাজনক হতে পারে।

### 4.1 Apps মেনু খুঁজুন

Alchemy Dashboard-এ লগইন করার পর নিচের মেনুতে যান:

**Team Overview > Apps**

আপনার অ্যাকাউন্টের ইন্টারফেস সংস্করণ অনুযায়ী মেনুর অবস্থান বা নাম কিছুটা ভিন্ন হতে পারে।

### 4.2 Create new app-এ ক্লিক করুন

Apps পেজে **Create new app** বাটনে ক্লিক করুন।

এরপর একটি অ্যাপ তৈরির ফর্ম খুলবে। সেখানে প্রজেক্টের তথ্য দিতে হবে।

### 4.3 অ্যাপের তথ্য পূরণ করুন

সাধারণত নিচের তথ্যগুলো পূরণ করতে হয়:

- **App Name:** অ্যাপ বা প্রজেক্টের নাম
- **Description:** প্রজেক্টের বিবরণ
- **Chains:** ব্যবহার করতে চান এমন ব্লকচেইন নেটওয়ার্ক
- **Services:** প্রয়োজনীয় পরিষেবা বা ফিচার

উদাহরণস্বরূপ, আপনার প্রজেক্ট Ethereum নেটওয়ার্ক ব্যবহার করলে Chains থেকে Ethereum নির্বাচন করুন।

### 4.4 অ্যাপ তৈরি সম্পন্ন করুন

প্রয়োজনীয় তথ্য পূরণ করার পর **Create App** বাটনে ক্লিক করুন।

অ্যাপ সফলভাবে তৈরি হলে এটি Apps তালিকায় দেখা যাবে।

## 5. Alchemy API Key কীভাবে সংগ্রহ করবেন?

অ্যাপ তৈরি হয়ে গেলে আপনি সেটির API Key দেখতে পারবেন।

### 5.1 অ্যাপের বিস্তারিত পেজ খুলুন

Alchemy Dashboard-এর Apps তালিকা থেকে আপনার তৈরি করা অ্যাপটি নির্বাচন করুন।

অ্যাপের বিস্তারিত পেজে API-সম্পর্কিত তথ্য দেখতে পাবেন।

### 5.2 API Key কপি করুন

অ্যাপের বিস্তারিত পেজে **API Key** অপশনটি খুঁজুন।

কপি বাটনে ক্লিক করে API Key কপি করুন।

API Key হলো একটি প্রমাণীকরণ তথ্য, যা আপনার অ্যাপ্লিকেশন Alchemy পরিষেবায় অনুরোধ পাঠানোর জন্য ব্যবহার করে। এটি অন্যদের কাছে প্রকাশ করবেন না।

### 5.3 Endpoints দেখুন

অ্যাপের বিস্তারিত পেজে **Endpoints** ট্যাব থেকেও বিভিন্ন নেটওয়ার্কের API Endpoint দেখা যায়।

Ethereum Mainnet RPC Endpoint-এর উদাহরণ:

```
https://eth-mainnet.g.alchemy.com/v2/YOUR_API_KEY
```

এখানে `YOUR_API_KEY`-এর জায়গায় আপনার আসল API Key বসান।

উল্লেখ্য, TRXAPI হলো TRON Energy Rental-সংক্রান্ত একটি স্বতন্ত্র পরিষেবা। এর সঙ্গে Alchemy-এর Ethereum RPC Endpoint-এর কোনো সম্পর্ক নেই।

## 6. API Key সঠিকভাবে কাজ করছে কি না পরীক্ষা করুন

API Key কপি করার পর একটি API Request পাঠিয়ে পরীক্ষা করতে পারেন এটি সঠিকভাবে কাজ করছে কি না।

### 6.1 টেস্ট কমান্ড চালান

টার্মিনাল বা Command Line Tool খুলে নিচের কমান্ডটি চালান।

`YOUR_API_KEY`-এর জায়গায় আপনার আসল API Key বসান।

```
curl https://eth-mainnet.g.alchemy.com/v2/YOUR_API_KEY \
-X POST \
-H "Content-Type: application/json" \
-d '{"jsonrpc":"2.0","method":"eth_blockNumber","params":[],"id":1}'
```

### 6.2 রেসপন্স পরীক্ষা করুন

অনুরোধ সফলভাবে সম্পন্ন হলে নিচের মতো একটি JSON Response দেখতে পারেন:

```
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": "0x..."
}
```

`result` ফিল্ডে ব্লক নম্বর দেখা গেলে বুঝবেন API Request সফলভাবে প্রসেস হয়েছে।

যদি কোনো Error আসে, তাহলে API Key, Endpoint, নেটওয়ার্ক সেটিংস এবং Request Format পরীক্ষা করুন।

## 7. Alchemy API Key ব্যবহারের সময় সতর্কতা

API Key সংগ্রহ করার পর সেটি নিরাপদে সংরক্ষণ করা গুরুত্বপূর্ণ।

### 7.1 API Key প্রকাশ করবেন না

আপনার API Key পাবলিক GitHub Repository, প্রকাশ্য ডকুমেন্ট বা Client-side Code-এ সরাসরি রাখবেন না।

সম্ভব হলে API Key সংরক্ষণের জন্য Environment Variables অথবা Server-side Settings ব্যবহার করুন।

### 7.2 API Key এবং Access Key-এর পার্থক্য বুঝুন

Alchemy API Key-এর পাশাপাশি Access Key-সম্পর্কিত ব্যবস্থাপনা সুবিধাও প্রদান করে।

দুটির ব্যবহার ও পরিচালনার পদ্ধতি আলাদা হতে পারে। তাই আপনার প্রজেক্টের প্রয়োজন অনুযায়ী সঠিক Authentication পদ্ধতি বেছে নিতে অফিসিয়াল ডকুমেন্টেশন দেখুন।

### 7.3 সঠিক নেটওয়ার্ক Endpoint ব্যবহার করুন

Ethereum Mainnet এবং Ethereum Sepolia-এর মতো নেটওয়ার্কের Endpoint আলাদা।

Mainnet এবং Testnet যেন ভুল করে একে অপরের পরিবর্তে ব্যবহার না হয়, সেদিকে খেয়াল রাখুন।

### 7.4 API ব্যবহার ও চার্জ পরীক্ষা করুন

আপনার Alchemy অ্যাকাউন্টের API ব্যবহার এবং চার্জ-সম্পর্কিত তথ্য নিয়মিত পরীক্ষা করুন।

প্রজেক্টের আকার অনুযায়ী API ব্যবহারের পরিমাণ পরিবর্তিত হতে পারে। তাই আপনার অ্যাকাউন্টে প্রযোজ্য মূল্য নির্ধারণ এবং ব্যবহারসীমা সম্পর্কে জেনে নিন।

## 8. Alchemy রেজিস্ট্রেশন ও API Key সম্পর্কিত সাধারণ প্রশ্ন

### Q1: Alchemy-তে অ্যাকাউন্ট তৈরি করা কি বিনামূল্যে?

Alchemy নতুন ব্যবহারকারীদের জন্য Free Plan প্রদান করে, তবে কিছু ফিচার এবং ব্যবহারের সীমাবদ্ধতা থাকতে পারে। সর্বশেষ মূল্য এবং ব্যবহারসীমা জানতে অফিসিয়াল ওয়েবসাইট দেখুন।

### Q2: API Key খুঁজে না পেলে কী করবেন?

Alchemy Dashboard-এ লগইন করুন। এরপর Apps মেনু থেকে সংশ্লিষ্ট অ্যাপ নির্বাচন করুন। অ্যাপের বিস্তারিত পেজে API Key এবং Endpoints-এর তথ্য পাবেন।

### Q3: একাধিক API Key তৈরি করা যায় কি?

প্রজেক্ট এবং অ্যাপ পরিচালনার পদ্ধতির ওপর নির্ভর করে একাধিক অ্যাপ ও সংশ্লিষ্ট API Authentication তথ্য পরিচালনা করা যেতে পারে। বিস্তারিত জানতে Dashboard এবং অফিসিয়াল ডকুমেন্টেশন দেখুন।

### Q4: API Key অন্যদের সঙ্গে শেয়ার করা যাবে কি?

API Key প্রকাশ্যে শেয়ার করার পরামর্শ দেওয়া হয় না। এটি প্রকাশ হয়ে গেলে অন্যরাও আপনার API Key ব্যবহার করে Request পাঠাতে পারে। তাই এটি নিরাপদে সংরক্ষণ করুন।

### Q5: API Key কাজ করছে না কেন?

নিচের বিষয়গুলো পরীক্ষা করুন:

- API Key সঠিকভাবে কপি করা হয়েছে কি না।
- Endpoint ঠিকানা সঠিক কি না।
- নির্বাচিত ব্লকচেইন নেটওয়ার্ক সঠিক কি না।
- API Request-এর Format সঠিক কি না।
- অ্যাকাউন্টের ব্যবহারসীমা বা পরিষেবার অবস্থার কোনো সমস্যা আছে কি না।

## 9. উপসংহার

2. ইমেইল অথবা সমর্থিত লগইন পদ্ধতিতে রেজিস্ট্রেশন করুন।
3. Dashboard-এ লগইন করুন।
4. Apps মেনু থেকে একটি নতুন অ্যাপ তৈরি করুন।
5. প্রয়োজনীয় ব্লকচেইন নেটওয়ার্ক নির্বাচন করুন।
6. অ্যাপের বিস্তারিত পেজ থেকে API Key কপি করুন।
