# Guide d'inscription à Alchemy : comment créer un compte et obtenir une clé API ?

Alchemy est une plateforme d'infrastructure blockchain conçue pour les développeurs Web3. Elle propose des outils et des services permettant de se connecter aux réseaux blockchain, d'accéder aux points de terminaison RPC, de consulter les données on-chain et de développer des applications décentralisées.

Si vous développez un portefeuille Web3, un projet NFT, un explorateur blockchain ou une application utilisant des contrats intelligents, vous aurez peut-être besoin d'un compte Alchemy et d'une clé API pour connecter votre projet à un réseau blockchain.

Dans ce guide, nous allons vous expliquer comment vous inscrire sur Alchemy, créer une application, obtenir votre clé API et vérifier que votre connexion fonctionne correctement.

En explorant les outils liés au développement blockchain et aux paiements en ligne, vous pouvez également découvrir des services indépendants comme CoinePay et TRXAPI. CoinePay propose des services de cartes virtuelles, tandis que TRXAPI propose la location d'énergie sur le réseau TRON. Aucun de ces services n'est officiellement affilié à Alchemy.

## 1. Qu'est-ce qu'Alchemy ?

Alchemy est une plateforme d'infrastructure blockchain qui aide les développeurs à connecter leurs applications aux réseaux blockchain sans avoir à créer et à maintenir leurs propres nœuds.

Avec Alchemy, les développeurs peuvent :

- Se connecter aux réseaux blockchain pris en charge.
- Accéder aux données blockchain via des API RPC.
- Consulter les informations des portefeuilles et des transactions.
- Récupérer des données liées aux NFT.
- Surveiller les activités et les transactions blockchain.
- Développer et gérer des applications Web3.

Pour les débutants, Alchemy simplifie le développement blockchain en fournissant une infrastructure et des services API prêts à l'emploi.

## 2. De quoi avez-vous besoin avant de vous inscrire sur Alchemy ?

Avant de créer un compte Alchemy, préparez les éléments suivants.

### Une adresse e-mail valide

Vous aurez besoin d'une adresse e-mail pour vous inscrire, vérifier votre compte ou recevoir des notifications importantes concernant la sécurité.

Assurez-vous de pouvoir accéder à cette adresse e-mail pendant toute la procédure.

### Une connexion Internet stable

Alchemy est une plateforme en ligne. Vous avez besoin d'une connexion Internet pour accéder au site officiel, au tableau de bord et aux outils destinés aux développeurs.

### Choisir un réseau blockchain

Si vous avez déjà un projet de développement, déterminez le réseau auquel vous souhaitez vous connecter.

Par exemple :

- Ethereum Mainnet : le réseau principal d'Ethereum.
- Ethereum Sepolia : un réseau de test Ethereum.
- Base : un réseau blockchain basé sur la technologie Ethereum.

Si vous débutez dans le développement blockchain, vous pouvez commencer par un réseau de test afin de découvrir les fonctionnalités disponibles.

## 3. Comment créer un compte Alchemy ?

### Étape 1 : Visiter le site officiel d'Alchemy

Ouvrez le site officiel d'Alchemy :

[https://www.alchemy.com/](https://www.alchemy.com/)

Recherchez le bouton Sign Up, Sign In ou Get Started.

Cliquez sur l'option d'inscription pour commencer la création de votre compte.

### Étape 2 : Créer votre compte

Suivez les instructions affichées sur la page d'inscription.

Selon les options disponibles, vous pourrez vous inscrire avec une adresse e-mail ou utiliser une méthode de connexion tierce compatible.

Si vous choisissez l'inscription par e-mail :

1. Saisissez votre adresse e-mail.
2. Complétez les informations demandées.
3. Suivez les instructions pour vérifier votre adresse e-mail ou effectuer les contrôles de sécurité supplémentaires.
4. Connectez-vous une fois l'inscription terminée.

Les méthodes d'inscription et les exigences de vérification peuvent évoluer. Suivez toujours les instructions affichées sur le site officiel d'Alchemy.

### Étape 3 : Accéder au tableau de bord Alchemy

Après votre inscription, rendez-vous sur le tableau de bord Alchemy :

[https://dashboard.alchemy.com/](https://dashboard.alchemy.com/)

Le Dashboard est l'espace principal permettant de gérer vos applications, vos clés API, vos réseaux blockchain et les paramètres de vos services.

Si vous êtes un nouvel utilisateur, Alchemy peut avoir déjà créé une application par défaut et une clé API pour votre compte.

Vérifiez d'abord les applications existantes avant d'en créer une nouvelle. Il est possible que vous puissiez utiliser directement l'application par défaut.

## 4. Comment créer une application sur Alchemy ?

Une application Alchemy permet de connecter votre projet aux réseaux blockchain sélectionnés et fournit les identifiants ainsi que les points de terminaison nécessaires pour envoyer des requêtes.

Vous pouvez créer plusieurs applications pour différents projets ou environnements de développement.

### Étape 1 : Ouvrir la section Apps

Connectez-vous au Alchemy Dashboard.

Ouvrez Team Overview depuis le menu de votre équipe, puis sélectionnez l'onglet Apps.

Recherchez l'option Create new app et cliquez dessus.

### Étape 2 : Renseigner les informations de l'application

Alchemy vous demandera de configurer votre nouvelle application.

Les paramètres disponibles peuvent inclure :

App Name : Saisissez un nom permettant d'identifier votre projet. Par exemple, My Web3 Project.

Description : Ajoutez une courte description de l'objectif de l'application. Ce champ peut être facultatif.

Chains : Sélectionnez les réseaux blockchain auxquels votre application doit accéder.

Services : Choisissez les services nécessaires à votre projet.

Si vous développez une application Ethereum, sélectionnez le réseau Ethereum correspondant.

Si vous souhaitez simplement apprendre ou effectuer des tests, privilégiez d'abord un réseau de test.

### Étape 3 : Créer l'application

Vérifiez les paramètres de votre application.

Assurez-vous que le nom, les réseaux sélectionnés et les services activés sont corrects.

Cliquez sur Create App pour terminer la procédure.

Une fois l'application créée, Alchemy vous redirigera vers sa page de détails.

## 5. Comment obtenir votre clé API Alchemy ?

La clé API sert à authentifier les requêtes envoyées aux services Alchemy associés à votre application.

Suivez les étapes ci-dessous pour la trouver.

### Étape 1 : Ouvrir votre application

Accédez à la section Apps du Alchemy Dashboard.

Recherchez l'application que vous venez de créer, puis cliquez sur son nom pour ouvrir sa page de détails.

### Étape 2 : Copier votre clé API

Sur la page de détails de l'application, recherchez la clé API, généralement affichée dans la partie supérieure droite.

Cliquez sur le bouton de copie pour copier la clé.

Conservez-la dans un endroit sécurisé afin de pouvoir l'utiliser dans votre projet de développement.

Ne publiez jamais votre véritable clé API sur un site public, dans un dépôt GitHub public ou dans tout autre espace accessible à des personnes non autorisées.

### Étape 3 : Trouver votre API Endpoint

Après avoir obtenu votre clé API, ouvrez l'onglet Endpoints sur la page de détails de votre application.

Vous pourrez y consulter les points de terminaison HTTP et WebSocket des réseaux blockchain activés.

Par exemple, un endpoint HTTP RPC pour Ethereum Mainnet suit généralement ce format :

[https://eth-mainnet.g.alchemy.com/v2/YOUR_API_KEY](https://eth-mainnet.g.alchemy.com/v2/YOUR_API_KEY)

Remplacez YOUR_API_KEY par la clé API copiée depuis le Alchemy Dashboard.

Chaque réseau blockchain possède une adresse endpoint différente. Utilisez toujours celle qui correspond au réseau sélectionné.

## 6. Comment vérifier si votre clé API Alchemy fonctionne ?

Après avoir obtenu votre clé API, il est conseillé d'envoyer une requête simple afin de vérifier que votre configuration est correcte.

Cet exemple utilise Ethereum Mainnet et la méthode JSON-RPC eth_blockNumber pour récupérer le numéro du dernier bloc.

### Étape 1 : Préparer votre RPC Endpoint

Utilisez le format suivant :

[https://eth-mainnet.g.alchemy.com/v2/YOUR_API_KEY](https://eth-mainnet.g.alchemy.com/v2/YOUR_API_KEY)

Remplacez YOUR_API_KEY par votre véritable clé API.

### Étape 2 : Envoyer une requête avec curl

Si curl est disponible sur votre ordinateur, ouvrez un terminal et exécutez la commande suivante :

```
curl https://eth-mainnet.g.alchemy.com/v2/YOUR_API_KEY \
-X POST \
-H "Content-Type: application/json" \
-d '{"jsonrpc":"2.0","method":"eth_blockNumber","params":[],"id":1}'
```

N'oubliez pas de remplacer YOUR_API_KEY par votre véritable clé avant d'exécuter la commande.

### Étape 3 : Vérifier la réponse

Si la clé API et l'endpoint sont correctement configurés, vous devriez recevoir une réponse JSON similaire à celle-ci :

```
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": "0x..."
}
```

Le champ result contient le numéro du bloc au format hexadécimal.

Si la requête renvoie une erreur, vérifiez que votre clé API est correcte, que le réseau correspondant est activé et que le format de la requête est valide.

## 7. Conseils importants pour protéger votre clé API

Votre clé API est un identifiant important pour accéder aux services Alchemy. Suivez ces bonnes pratiques afin de protéger votre compte et vos applications.

### Ne publiez pas votre clé API

N'exposez jamais votre véritable clé API dans des dépôts de code publics, des forums ou des pages web accessibles à tous.

Pour vos projets de développement, privilégiez le stockage de la clé dans des variables d'environnement ou des fichiers de configuration sécurisés.

### Comprendre la différence entre API Keys et Access Keys

Alchemy propose différents types d'identifiants pour répondre à différents besoins.

Une clé API d'application est généralement utilisée pour accéder aux endpoints RPC et aux API prises en charge associées à une application.

Les Access Keys sont utilisées dans certains scénarios d'authentification et de gestion. Elles peuvent également permettre de définir des contrôles d'accès supplémentaires.

Ne supposez pas que ces identifiants sont interchangeables. Consultez la documentation officielle d'Alchemy avant de les utiliser.

### Sélectionner le bon réseau blockchain

Assurez-vous que votre application est configurée pour le réseau que vous souhaitez réellement utiliser.

Par exemple :

- Ethereum Mainnet est utilisé pour le réseau de production Ethereum.
- Ethereum Sepolia est utilisé pour les tests.
- Base est un réseau blockchain distinct.

L'utilisation d'un endpoint appartenant à un mauvais réseau peut entraîner des résultats inattendus ou des erreurs.

### Surveiller l'utilisation et les tarifs

Alchemy propose différents forfaits. Les fonctionnalités disponibles, les limites d'utilisation et les tarifs peuvent évoluer.

Avant d'utiliser Alchemy dans une application de production, consultez votre forfait actuel, vos limites d'utilisation et les informations de facturation dans le Dashboard.

N'oubliez pas non plus que les autres services liés à la blockchain peuvent avoir des fonctions complètement différentes. Par exemple, TRXAPI se concentre sur la location d'énergie TRON, tandis qu'Alchemy fournit une infrastructure pour le développement blockchain.

## 8. Questions fréquentes sur l'inscription à Alchemy

### Q1 : L'inscription à Alchemy est-elle gratuite ?

La création d'un compte et l'utilisation de la plateforme sont deux choses différentes.

Alchemy propose plusieurs forfaits. Les fonctionnalités gratuites, les limites de requêtes et les tarifs dépendent du forfait en vigueur.

La création d'un compte ne signifie pas nécessairement que toutes les requêtes API et tous les services sont gratuits.

Consultez la page officielle des tarifs pour obtenir les informations les plus récentes :

[https://www.alchemy.com/pricing](https://www.alchemy.com/pricing)

### Q2 : Que faire si je ne trouve pas ma clé API après l'inscription ?

Commencez par vous connecter au Alchemy Dashboard et ouvrez la section Apps.

Vérifiez si votre compte dispose déjà d'une application par défaut.

Si une application existe, ouvrez sa page de détails et recherchez la clé API.

Si aucune application n'est disponible, sélectionnez Create new app et terminez la configuration.

### Q3 : Puis-je créer plusieurs clés API Alchemy ?

Vous pouvez créer plusieurs applications pour différents projets ou environnements de développement et gérer leurs identifiants séparément.

Par exemple, vous pouvez utiliser des applications distinctes pour le développement, les tests et la production.

Cela facilite l'organisation des projets et le suivi individuel de leur utilisation.

### Q4 : Puis-je partager ma clé API avec d'autres développeurs ?

Il est préférable d'éviter de la partager inutilement.

Si d'autres développeurs doivent accéder à vos services Alchemy, utilisez les autorisations d'équipe et des méthodes sécurisées de gestion des identifiants.

Ne publiez pas vos identifiants personnels ou ceux de votre projet dans des espaces publics.

### Q5 : Pourquoi ma clé API Alchemy ne fonctionne-t-elle pas ?

Les causes les plus fréquentes sont les suivantes :

1. La clé API a été copiée incorrectement.
2. L'endpoint RPC est incorrect.
3. Le réseau blockchain nécessaire n'est pas activé.
4. La méthode ou les paramètres de la requête ne sont pas valides.
5. L'application est soumise à des restrictions d'utilisation ou d'autorisation.
6. Un problème de connexion Internet est survenu.

Vérifiez d'abord les paramètres de votre application et la configuration de l'endpoint. Vous pouvez également consulter la documentation officielle d'Alchemy pour obtenir des instructions de dépannage.

## 9. Conclusion : terminer votre inscription à Alchemy et obtenir une clé API

S'inscrire sur Alchemy et obtenir une clé API constitue une première étape importante pour les développeurs qui souhaitent créer des applications Web3.

La procédure complète peut être résumée ainsi :

1. Visitez le site officiel d'Alchemy.
2. Créez un compte et connectez-vous.
3. Ouvrez le Alchemy Dashboard.
4. Créez une application si vous avez besoin d'une configuration distincte pour votre projet.
5. Sélectionnez les réseaux blockchain et les services nécessaires.
6. Ouvrez la page de détails de l'application et copiez votre clé API.
7. Consultez l'onglet Endpoints pour trouver la bonne adresse RPC.
8. Envoyez une requête de test afin de vérifier que votre configuration fonctionne.

Pour les débutants, il est conseillé de commencer par une simple requête de données blockchain. Une fois que vous maîtrisez les clés API, les endpoints RPC et la configuration des réseaux, vous pourrez progressivement passer à des projets Web3 plus avancés.

Si vous explorez également d'autres services liés à la blockchain, prenez le temps de comprendre leurs différentes fonctions.
