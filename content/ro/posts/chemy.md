## 1. Ce este Alchemy?

Alchemy este o platformă de infrastructură blockchain care ajută dezvoltatorii să își conecteze aplicațiile la diferite rețele blockchain fără să fie nevoie să construiască și să întrețină propriile noduri.

- Să obțină date despre NFT-uri.
- Să monitorizeze activitățile și tranzacțiile blockchain.
- Să dezvolte și să gestioneze aplicații Web3.

Pentru începători, Alchemy simplifică dezvoltarea blockchain prin furnizarea unei infrastructuri și a unor servicii API gata de utilizare.

## 4. Cum să creezi o aplicație în Alchemy?

O aplicație Alchemy conectează proiectul tău la rețelele blockchain selectate și furnizează datele de autentificare și endpoint-urile necesare pentru trimiterea solicitărilor.

Poți crea aplicații separate pentru proiecte sau medii de dezvoltare diferite.

### Pasul 1: Deschide secțiunea Apps

Conectează-te la Alchemy Dashboard.

Deschide Team Overview din meniul echipei, apoi selectează fila Apps.

Caută opțiunea Create new app și apasă pe aceasta.

### Pasul 2: Introdu informațiile aplicației

Alchemy îți va solicita să configurezi noua aplicație.

Setările disponibile pot include:

App Name: Introdu un nume care să identifice proiectul. De exemplu, My Web3 Project.

Description: Adaugă o scurtă descriere a scopului aplicației. Acest câmp poate fi opțional.

Chains: Selectează rețelele blockchain la care aplicația trebuie să aibă acces.

Services: Alege serviciile necesare proiectului tău.

Dacă dezvolți o aplicație Ethereum, selectează rețeaua Ethereum corespunzătoare.

Dacă doar înveți sau efectuezi teste, este recomandat să începi cu o rețea de test.

### Pasul 3: Creează aplicația

Verifică setările aplicației.

Asigură-te că numele, rețelele selectate și serviciile activate sunt corecte.

Apasă pe Create App pentru a finaliza procesul.

După crearea aplicației, Alchemy te va redirecționa către pagina cu detaliile acesteia.

## 5. Cum să obții API Key de la Alchemy?

API Key este utilizată pentru autentificarea solicitărilor către serviciile Alchemy asociate aplicației tale.

Urmează pașii de mai jos pentru a găsi cheia.

### Pasul 1: Deschide aplicația

Accesează secțiunea Apps din Alchemy Dashboard.

Găsește aplicația pe care tocmai ai creat-o și apasă pe numele acesteia pentru a deschide pagina cu detalii.

### Pasul 2: Copiază API Key

Pe pagina cu detaliile aplicației, caută API Key, care este afișată de obicei în partea din dreapta sus.

Apasă pe butonul de copiere pentru a copia cheia.

Păstreaz-o într-un loc sigur pentru a o putea utiliza în proiectul tău de dezvoltare.

Nu publica niciodată cheia API reală pe site-uri publice, în depozite publice GitHub sau în alte locuri unde ar putea fi accesată de persoane neautorizate.

### Pasul 3: Găsește API Endpoint

După ce ai obținut API Key, deschide fila Endpoints de pe pagina cu detaliile aplicației.

În această secțiune poți consulta endpoint-urile HTTP și WebSocket pentru rețelele blockchain activate.

De exemplu, un endpoint HTTP RPC pentru Ethereum Mainnet are de obicei următorul format:

[https://eth-mainnet.g.alchemy.com/v2/YOUR_API_KEY](https://eth-mainnet.g.alchemy.com/v2/YOUR_API_KEY)

Înlocuiește YOUR_API_KEY cu cheia API copiată din Alchemy Dashboard.

Fiecare rețea blockchain are o adresă de endpoint diferită. Utilizează întotdeauna adresa corespunzătoare rețelei selectate.

## 6. Cum să verifici dacă API Key Alchemy funcționează?

După ce ai obținut API Key, este recomandat să trimiți o solicitare simplă pentru a verifica dacă setările sunt corecte.

Acest exemplu utilizează Ethereum Mainnet și metoda JSON-RPC eth_blockNumber pentru a obține numărul celui mai recent bloc.

### Pasul 1: Pregătește RPC Endpoint

Utilizează următorul format:

[https://eth-mainnet.g.alchemy.com/v2/YOUR_API_KEY](https://eth-mainnet.g.alchemy.com/v2/YOUR_API_KEY)

Înlocuiește YOUR_API_KEY cu cheia ta API reală.

### Pasul 2: Trimite o solicitare folosind curl

Dacă curl este disponibil pe computerul tău, deschide un terminal și execută următoarea comandă:

```
curl https://eth-mainnet.g.alchemy.com/v2/YOUR_API_KEY \
-X POST \
-H "Content-Type: application/json" \
-d '{"jsonrpc":"2.0","method":"eth_blockNumber","params":[],"id":1}'
```

Nu uita să înlocuiești YOUR_API_KEY cu cheia ta reală înainte de a executa comanda.

### Pasul 3: Verifică răspunsul

Dacă API Key și endpoint-ul sunt configurate corect, ar trebui să primești un răspuns JSON similar cu următorul:

```
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": "0x..."
}
```

Câmpul result conține numărul blocului în format hexadecimal.

Dacă solicitarea returnează o eroare, verifică dacă API Key este corectă, dacă rețeaua corespunzătoare este activată și dacă formatul solicitării este valid.

## 7. Sfaturi importante pentru protejarea API Key

API Key este o credențială importantă pentru accesarea serviciilor Alchemy. Respectă următoarele recomandări pentru a-ți proteja contul și aplicațiile.

### Nu publica API Key

Nu expune niciodată cheia API reală în depozite publice de cod, forumuri online sau pagini web accesibile publicului.

Pentru proiectele de dezvoltare, este recomandat să stochezi cheia în variabile de mediu sau în fișiere de configurare securizate.

### Înțelege diferența dintre API Keys și Access Keys

Alchemy oferă diferite tipuri de credențiale pentru scopuri diferite.

O API Key asociată unei aplicații este utilizată de obicei pentru accesarea endpoint-urilor RPC și a API-urilor compatibile asociate aplicației.

Access Keys sunt utilizate în anumite scenarii de autentificare și administrare. Acestea pot oferi și controale suplimentare pentru gestionarea permisiunilor.

Nu presupune că aceste credențiale sunt interschimbabile. Consultă documentația oficială Alchemy înainte de a le utiliza.

### Selectează rețeaua blockchain corectă

Asigură-te că aplicația este configurată pentru rețeaua pe care dorești să o utilizezi.

De exemplu:

- Ethereum Mainnet este utilizată pentru rețeaua de producție Ethereum.
- Ethereum Sepolia este utilizată pentru testare.
- Base este o rețea blockchain separată.

Utilizarea unui endpoint care aparține unei rețele greșite poate produce rezultate neașteptate sau erori.

### Monitorizează utilizarea și prețurile

Alchemy oferă diferite planuri de utilizare. Funcțiile disponibile, limitele și prețurile se pot modifica.

Înainte de a utiliza Alchemy într-o aplicație de producție, verifică planul actual, limitele de utilizare și informațiile de facturare din Dashboard.

Reține că și alte servicii legate de blockchain pot avea funcții complet diferite. De exemplu, TRXAPI se concentrează pe închirierea energiei TRON, în timp ce Alchemy oferă infrastructură pentru dezvoltarea blockchain.

### Q2: Ce trebuie să fac dacă nu găsesc API Key după înregistrare?

Mai întâi, conectează-te la Alchemy Dashboard și deschide secțiunea Apps.

Verifică dacă în contul tău există deja o aplicație implicită.

Dacă nu este disponibilă nicio aplicație, selectează Create new app și finalizează configurarea.

### Q3: Pot crea mai multe API Keys în Alchemy?

Poți crea mai multe aplicații pentru proiecte sau medii de dezvoltare diferite și poți gestiona separat credențialele acestora.

De exemplu, poți utiliza aplicații diferite pentru dezvoltare, testare și producție.

Acest lucru facilitează organizarea proiectelor și monitorizarea separată a utilizării.

### Q4: Pot partaja API Key cu alți dezvoltatori?

Nu este recomandat să partajezi cheia fără un motiv întemeiat.

Dacă alți dezvoltatori au nevoie de acces la serviciile tale Alchemy, utilizează permisiunile echipei și metode sigure de gestionare a credențialelor.

Nu publica datele personale de acces sau credențialele proiectului în locuri publice.

### Q5: De ce nu funcționează API Key Alchemy?

Cele mai frecvente cauze includ:

1. API Key a fost copiată incorect.
2. Endpoint-ul RPC este incorect.
3. Rețeaua blockchain necesară nu este activată.
4. Metoda sau parametrii solicitării nu sunt valizi.
5. Aplicația are restricții de utilizare sau permisiuni.
6. Există o problemă cu conexiunea la internet.

Verifică mai întâi setările aplicației și configurația endpoint-ului. Poți consulta și documentația oficială Alchemy pentru instrucțiuni de depanare.
