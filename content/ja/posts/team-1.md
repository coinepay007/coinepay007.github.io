# Claude Teamにメンバーを追加する方法｜設定・権限管理ガイド

Claude Teamは、企業やチームが同じ組織内で共同作業を行うためのサービスです。管理者はメンバーを招待したり、役割を管理したり、アクセス権限を設定したりすることで、チームの運営を効率化できます。

海外サイトでの支払いやデジタルサービスのサブスクリプションに利用できる決済サービスをお探しの場合は、バーチャルカードプラットフォームのCoinePayもご確認ください。海外サイトやデジタルサービスの支払いに利用できる決済手段を提供しています。

CoinePay：[https://www.coinepay.net/register?referrer=RFGSSDZ9](https://www.coinepay.net/register?referrer=RFGSSDZ9)

この記事では、Claude Teamへのメンバー招待方法、招待の管理、ユーザー権限の設定、よくあるトラブルの解決方法について詳しく解説します。

## 1. メンバーを招待する前に確認すること

メンバーを招待する前に、以下の条件を確認してください。

- Claude Teamの有効なサブスクリプションを利用していること
- 自分のアカウントにメンバーを招待する権限があること
- 組織に空きシートがある、または追加購入できること
- 招待する相手のメールアドレスが正しいこと
- 招待されるユーザーが組織のメールアドレス要件を満たしていること

Claude Teamの組織作成には、通常5人以上のメンバーが必要です。また、Anthropicでは利用するメールアドレスのドメインに関する条件が設けられている場合があります。Gmail、Yahoo、Hotmailなどの個人用メールアドレスは、組織用メールアドレスの要件を満たさない可能性があります。

具体的な条件は変更される場合があるため、組織を作成する前にAnthropicの公式ドキュメントを確認してください。

## 2. Claude Teamにメンバーを招待する方法

メンバーの追加は、組織の設定画面から行います。

### ステップ1：組織の設定を開く

Claude Teamのアカウントにログインします。

組織の設定を開き、メンバー管理またはアクセス管理に関する項目に移動します。

### ステップ2：メンバー管理を開く

メンバーの追加または招待に関する項目を探します。

表示される操作項目は、自分の役割や組織の設定によって異なる場合があります。

### ステップ3：メールアドレスを入力する

招待したいメンバーのメールアドレスを入力します。

送信ミスを防ぐため、入力したアドレスに間違いがないか確認してください。

### ステップ4：招待を送信する

入力内容を確認して、招待を送信します。

招待されたユーザーには、Claude Teamの組織に参加するための手順が記載されたメールが届きます。

参加を完了するには、メールに記載された案内に従って操作する必要があります。

## 3. 複数のメンバーを一括で追加する方法

会社で複数のメンバーを追加する場合は、一括追加機能を利用すると便利です。

招待を1件ずつ送信する代わりに、この機能が利用できる場合は、メンバー管理画面に複数のメールアドレスをまとめて入力できます。

送信を確定する前に、次の点を確認してください。

- すべてのメールアドレスが正しいこと
- 重複したメールアドレスが含まれていないこと
- 組織に十分な空きシートがあること
- 招待するユーザーが同じ組織に参加すること

一括追加機能は、新入社員の受け入れやプロジェクトチームの編成などに特に便利です。

## 4. 招待リンクを使ってメンバーを追加する方法

Claude Teamでは、招待リンクを利用してユーザーを組織に参加させる方法も提供される場合があります。

複数のメンバーにアクセス権を共有したい場合に便利な方法です。

### 招待リンクの確認場所

組織の設定画面で、次の項目を探してください。

**Organization settings → Identity and access**

招待リンクの設定は、グローバルアクセス設定内にある場合があります。

### 招待リンクの使用方法

1. 組織の設定を開きます。
2. IDとアクセス管理のセクションに移動します。
3. 招待リンクの設定を探します。
4. 利用可能な招待リンクをコピーします。
5. 組織への参加を許可されたユーザーにのみ共有します。

### 招待リンクの有効期限

招待リンクには有効期限が設定されている場合があり、通常は90日間です。

リンクを無効化したり、新しいリンクを再生成したりすると、以前のリンクは直ちに使用できなくなります。

なお、シングルサインオン（SSO）を利用しているEnterprise組織では、この方法を利用できない場合があります。

招待リンクから参加したメンバーには、組織の設定に応じて、利用可能な中で最も低い種類のシートが割り当てられる場合があります。

## 5. Claude Teamの役割と権限について

Claude Teamでは、組織内の責任を分担するために複数のユーザー権限が用意されています。

### User

Userは、一般的なチームメンバーに割り当てられる標準的な役割です。

割り当てられたシートの種類に応じて、Claudeの機能や利用上限を利用できます。

### Admin

Adminは、組織内のさまざまな管理操作を実行できます。

主な権限は次のとおりです。

- 新しいメンバーを招待する
- メンバーを組織から削除する
- 保留中の招待をキャンセルする

ただし、Adminは通常、請求管理や他のメンバーの役割変更を行うことはできません。

### Owner

Ownerは、より広範な組織管理権限を持つ役割です。

組織の設定によって、次の操作が可能です。

- メンバーの管理
- メンバーの役割変更
- 組織設定の管理
- 請求に関する管理

### Primary Owner

Primary Ownerは、組織の主要な所有者です。

シートの管理や組織の重要な設定など、最も広範な管理権限を持っています。

通常、1つの組織に設定できるPrimary Ownerは1人です。

## 6. メンバーの役割を変更する方法

メンバーの権限を変更するには、OwnerまたはPrimary Ownerの権限が必要です。

### 変更手順

1. Claude Teamにログインします。
2. 組織の設定を開きます。
3. Membersセクションに移動します。
4. 変更したいメンバーを探します。
5. 現在の役割を選択します。
6. 変更可能な場合は、新しい役割を選択します。
7. 変更を確定します。

Admin権限のみを持つ管理者は、通常、他のメンバーの役割を変更できません。

役割を変更する前に、新しい権限がそのメンバーの実際の業務内容に適しているか確認してください。

## 7. Claude Teamからメンバーを削除する方法

社員が退職した場合や、Claude Teamへのアクセスが不要になった場合は、対象メンバーを組織から削除できます。

### 削除手順

1. 組織の設定を開きます。
2. Membersセクションに移動します。
3. 削除したいアカウントを探します。
4. 削除オプションを選択します。
5. 操作を確定します。

削除すると、そのメンバーの組織へのアクセス権は取り消されます。

### メンバーを削除するとシートはどうなる？

メンバーを削除すると、通常、そのメンバーに割り当てられていたシートが解放され、別のユーザーに割り当てられるようになります。

ただし、購入済みのシート総数が自動的に減るわけではありません。

支払い対象となるシート数を減らしたい場合は、シート管理と請求設定を別途確認する必要があります。

状況によっては、同じメールアドレスを使用して組織に再参加したユーザーが、アカウントに関連付けられた履歴を引き続き利用できる場合があります。

組織のOwner、特にPrimary Ownerには、自分自身のアカウントを削除しようとする際に制限が設けられている場合があります。

## 8. メンバー招待時によくある問題

### 招待メールが受信トレイに届かない

次の項目を確認してください。

- メールアドレスが正しいか
- メールが迷惑メールフォルダに振り分けられていないか
- メールサーバーがAnthropicからのメールをブロックしていないか
- 招待の有効期限が切れていないか

招待された相手にも、迷惑メールフォルダを確認してもらいましょう。

### 空きシートが不足していると表示される

このエラーは通常、組織に十分な空きシートがないことを意味します。

利用中のプランで可能な場合は、空きシートを確認するか、追加のシートを購入してください。

### ユーザーが組織に参加できない

考えられる原因は次のとおりです。

- 招待リンクの有効期限が切れている
- 招待がキャンセルされている
- メールアドレスが組織の要件を満たしていない
- 招待リンクが無効化されている、または新しいリンクに変更されている
- 招待を受け取ったアカウントとは別のアカウントでログインしようとしている

アクセス設定を確認し、必要に応じて新しい招待を送信してください。

### 招待が保留中のままになっている

送信済みであっても、まだ承認されていない招待は一定期間、保留状態になる場合があります。

メールによる招待は、21日後に有効期限が切れる場合があります。また、保留中の招待が組織のシートを占有することもあります。

相手に招待メールが届いていない場合は、メールアドレスを確認し、再送信できる場合は招待を送り直してください。

## 9. Claude Teamの組織管理に役立つポイント

アクセスや管理に関するトラブルを防ぐため、次のポイントを意識しましょう。

**役割は担当業務に応じて割り当てる**

すべてのメンバーにOwner権限を付与する必要はありません。高い権限は、組織の管理を担当するメンバーに限定しましょう。

**メンバーを定期的に確認する**

組織へのアクセスが不要になったアカウントは削除しましょう。

**利用可能なシート数を管理する**

新しいメンバーを追加する際に問題が発生しないよう、使用中のシート数と空きシート数を定期的に確認してください。

**招待リンクを安全に管理する**

アクセス用リンクを一般公開しないでください。参加を許可された相手にのみ共有しましょう。

**保留中の招待を確認する**

未承認の招待は、シート管理を複雑にする可能性があります。送信済み招待の状態を定期的に確認しましょう。

## 10. サブスクリプションと支払いの管理

Claude Teamの管理は、メンバー招待や権限設定だけではありません。組織のOwnerは、サブスクリプション、購入済みシート、請求情報についても管理する必要があります。

複数の海外デジタルサービスを利用している企業にとって、用途に合った決済ツールを用意しておくことは便利です。

CoinePayは、海外サイトやデジタルサービスのサブスクリプション向けに決済手段を提供するバーチャルカードプラットフォームです。実際に利用する前に、手数料、利用条件、対象店舗でのカード利用可否を確認してください。

CoinePay公式サイト：

[https://www.coinepay.net/register?referrer=RFGSSDZ9](https://www.coinepay.net/register?referrer=RFGSSDZ9)

また、TRONネットワークでUSDT送金を行う場合、ネットワークのリソースが取引コストに影響することがあります。

TRXAPIは、TRONネットワーク上のエネルギーレンタルサービスを提供しており、ブロックチェーン上の送金に必要なリソースの管理をサポートします。

TRXAPIアクセスページ：

[https://login.trxapi.io/energy](https://login.trxapi.io/energy)

TRXAPI招待コード：**RT9G2YGH**

これらのサービスは、それぞれ異なる用途に対応しています。CoinePayはバーチャルカードによる決済手段に関するサービスであり、TRXAPIはTRONネットワーク上の取引に必要なリソースの管理に関するサービスです。

## 11. まとめ

Claude Teamのメンバー管理では、主に次の操作を行います。メンバーの招待、役割の割り当て、アクセス権限の管理、不要になったアカウントの削除です。

組織を適切に管理するためには、メンバー一覧、保留中の招待、利用可能なシート数を定期的に確認することをおすすめします。

User、Admin、Owner、Primary Ownerの違いを理解しておけば、アクセス権限をより効率的に管理でき、必要以上の権限を付与することも防げます。

Claude Teamの機能や利用条件は変更される可能性があります。最新情報については、必ずAnthropicの公式ヘルプセンターを確認してください。
