# คู่มือสมัคร Alchemy: วิธีสร้างบัญชีและรับ API Key

Alchemy เป็นแพลตฟอร์มโครงสร้างพื้นฐานด้านบล็อกเชนที่ออกแบบมาสำหรับนักพัฒนา Web3 โดยให้บริการ RPC การเข้าถึงข้อมูลบนบล็อกเชน (On-chain Data) และเครื่องมือสำหรับพัฒนาแอปพลิเคชันแบบกระจายศูนย์ (DApp) คู่มือนี้จะแนะนำขั้นตอนการสมัครบัญชี Alchemy และวิธีรับ API Key อย่างละเอียด

หากคุณต้องการเครื่องมือชำระเงินออนไลน์สำหรับการใช้งานบริการ Web3 สามารถศึกษาบริการบัตรเสมือนของ CoinePay เพิ่มเติมได้ นอกจากนี้ ผู้ที่ต้องการจัดการค่าใช้จ่ายในการทำธุรกรรมบนเครือข่าย TRON สามารถดูบริการเช่าพลังงาน TRON จาก TRXAPI ได้เช่นกัน ทั้งสองบริการเป็นบริการอิสระที่แยกจาก Alchemy และไม่มีความร่วมมือหรือการเชื่อมต่ออย่างเป็นทางการกับ Alchemy

## 1. Alchemy คืออะไร?

Alchemy เป็นแพลตฟอร์มที่ให้บริการโครงสร้างพื้นฐานสำหรับการพัฒนาแอปพลิเคชันบล็อกเชน นักพัฒนาสามารถใช้ Alchemy เพื่อเชื่อมต่อกับเครือข่ายบล็อกเชน เรียกดูข้อมูล และโต้ตอบกับ Smart Contract ได้

คุณสมบัติหลักของ Alchemy ได้แก่

- **RPC Services:** ช่วยให้แอปพลิเคชันสามารถสื่อสารกับเครือข่ายบล็อกเชนได้
- **On-chain Data Access:** ช่วยเรียกดูข้อมูลธุรกรรม บล็อก และข้อมูลอื่น ๆ บนบล็อกเชน
- **Developer Tools:** เครื่องมือที่ช่วยในการพัฒนาและแก้ไขข้อผิดพลาดของแอปพลิเคชัน Web3
- **API Services:** ให้บริการ API สำหรับเชื่อมต่อกับเครือข่ายบล็อกเชนต่าง ๆ

หากต้องการเริ่มใช้งาน Alchemy คุณต้องสร้างบัญชีก่อน จากนั้นจึงรับ API Key สำหรับใช้กับโปรเจกต์ของคุณ

## 2. สิ่งที่ต้องเตรียมก่อนสมัคร Alchemy

ก่อนเริ่มสมัครบัญชี ควรเตรียมสิ่งต่อไปนี้ให้พร้อม

### 2.1 ที่อยู่อีเมลที่ใช้งานได้

คุณต้องมีอีเมลที่ใช้งานได้สำหรับลงทะเบียนบัญชี Alchemy และยืนยันตัวตนผ่านอีเมล

### 2.2 การเชื่อมต่ออินเทอร์เน็ตที่เสถียร

ในระหว่างการสมัคร คุณต้องยืนยันอีเมลและเข้าสู่ระบบ Dashboard จึงควรใช้อินเทอร์เน็ตที่เสถียร

### 2.3 เลือกเครือข่ายบล็อกเชนที่ต้องการใช้งาน

ก่อนสร้าง API Key ควรตรวจสอบก่อนว่าคุณต้องการใช้เครือข่ายบล็อกเชนใด

ตัวอย่างเช่น

- Ethereum Mainnet
- Ethereum Sepolia
- Base

ในขั้นตอนการสร้างแอป คุณจะต้องเลือกเครือข่ายให้ตรงกับความต้องการของโปรเจกต์

## 3. สมัครบัญชีผ่านเว็บไซต์ทางการของ Alchemy

### 3.1 เข้าสู่เว็บไซต์ทางการ

เปิดเว็บไซต์ทางการของ Alchemy

[https://www.alchemy.com/](https://www.alchemy.com/)

ที่หน้าแรก คลิกปุ่ม **Sign Up**, **Sign In** หรือ **Get Started**

### 3.2 ดำเนินการสมัครสมาชิก

ทำตามคำแนะนำที่แสดงบนหน้าจอ คุณสามารถสมัครด้วยอีเมลหรือเลือกใช้วิธีเข้าสู่ระบบผ่านบริการภายนอกที่รองรับ

หากสมัครด้วยอีเมล ให้ดำเนินการตามขั้นตอนต่อไปนี้

1. กรอกที่อยู่อีเมลของคุณ
2. ตั้งรหัสผ่านหรือทำตามคำแนะนำที่ปรากฏบนหน้าจอ
3. เปิดกล่องจดหมายอีเมลและค้นหาข้อความยืนยัน
4. ยืนยันอีเมลให้เรียบร้อย จากนั้นเข้าสู่ระบบบัญชีของคุณ

### 3.3 เข้าสู่ Dashboard

หลังจากเข้าสู่ระบบแล้ว ให้เปิด Alchemy Dashboard

[https://dashboard.alchemy.com/](https://dashboard.alchemy.com/)

Dashboard เป็นหน้าจอหลักสำหรับจัดการแอปพลิเคชันและ API Key ของคุณ

บางบัญชีอาจมีแอปเริ่มต้นหรือ API Key แสดงอยู่แล้วหลังจากสมัครสมาชิก ให้ตรวจสอบข้อมูลที่มีอยู่ก่อน และสร้างแอปใหม่หากจำเป็น

## 4. วิธีสร้างแอปใหม่ใน Alchemy

เพื่อให้จัดการ API Key ได้อย่างเป็นระเบียบ คุณสามารถสร้างแอปแยกสำหรับแต่ละโปรเจกต์ได้ตามความเหมาะสม

### 4.1 ค้นหาเมนู Apps

หลังจากเข้าสู่ระบบ Alchemy Dashboard แล้ว ให้เปิดเมนูต่อไปนี้

**Team Overview > Apps**

ตำแหน่งหรือชื่อเมนูอาจแตกต่างกันเล็กน้อยตามเวอร์ชันของอินเทอร์เฟซบัญชี

### 4.2 คลิก Create new app

ในหน้า Apps คลิกปุ่ม **Create new app**

จากนั้นหน้าสำหรับสร้างแอปใหม่จะปรากฏขึ้น เพื่อให้คุณกรอกข้อมูลของโปรเจกต์

### 4.3 กรอกข้อมูลแอป

โดยทั่วไปจะมีช่องข้อมูลดังต่อไปนี้

- **App Name:** ชื่อแอปหรือโปรเจกต์
- **Description:** คำอธิบายโปรเจกต์
- **Chains:** เครือข่ายบล็อกเชนที่ต้องการใช้งาน
- **Services:** บริการหรือฟีเจอร์ที่ต้องการ

ตัวอย่างเช่น หากโปรเจกต์ของคุณใช้เครือข่าย Ethereum ให้เลือก Ethereum ในส่วน Chains

### 4.4 สร้างแอปให้เสร็จสมบูรณ์

หลังจากกรอกข้อมูลที่จำเป็นทั้งหมดแล้ว คลิกปุ่ม **Create App**

เมื่อสร้างแอปสำเร็จ แอปดังกล่าวจะปรากฏในรายการ Apps

## 5. วิธีรับ Alchemy API Key

หลังจากสร้างแอปแล้ว คุณสามารถดู API Key ของแอปนั้นได้

### 5.1 เปิดหน้ารายละเอียดแอป

ในรายการ Apps ของ Alchemy Dashboard ให้เลือกแอปที่คุณเพิ่งสร้างขึ้น

จากนั้นระบบจะแสดงหน้ารายละเอียดแอป ซึ่งมีข้อมูลเกี่ยวกับ API

### 5.2 คัดลอก API Key

ค้นหาหัวข้อ **API Key** ในหน้ารายละเอียดแอป

คลิกปุ่มคัดลอกเพื่อคัดลอก API Key

API Key เป็นข้อมูลสำหรับการยืนยันตัวตนที่แอปพลิเคชันใช้ส่งคำขอไปยังบริการของ Alchemy คุณไม่ควรเปิดเผยข้อมูลนี้ให้ผู้อื่นทราบ

### 5.3 ดู Endpoints

คุณสามารถเปิดแท็บ **Endpoints** ในหน้ารายละเอียดแอป เพื่อดูที่อยู่ API Endpoint ของเครือข่ายต่าง ๆ ได้

ตัวอย่าง Ethereum Mainnet RPC Endpoint

```
https://eth-mainnet.g.alchemy.com/v2/YOUR_API_KEY
```

ให้แทนที่ `YOUR_API_KEY` ด้วย API Key จริงที่คุณได้รับ

โปรดทราบว่า TRXAPI เป็นบริการเช่าพลังงาน TRON ที่แยกต่างหาก และไม่มีความเกี่ยวข้องกับ Ethereum RPC Endpoint ของ Alchemy

## 6. ทดสอบว่า API Key ใช้งานได้หรือไม่

หลังจากคัดลอก API Key แล้ว คุณสามารถส่งคำขอ API จริงเพื่อทดสอบว่าคีย์ทำงานได้อย่างถูกต้องหรือไม่

### 6.1 เรียกใช้คำสั่งทดสอบ

เปิด Terminal หรือ Command Line Tool แล้วเรียกใช้คำสั่งต่อไปนี้

แทนที่ `YOUR_API_KEY` ด้วย API Key จริงของคุณ

```
curl https://eth-mainnet.g.alchemy.com/v2/YOUR_API_KEY \
-X POST \
-H "Content-Type: application/json" \
-d '{"jsonrpc":"2.0","method":"eth_blockNumber","params":[],"id":1}'
```

### 6.2 ตรวจสอบผลลัพธ์

หากคำขอทำงานสำเร็จ คุณอาจได้รับ JSON Response ที่มีลักษณะดังนี้

```
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": "0x..."
}
```

หากมีหมายเลขบล็อกปรากฏในฟิลด์ `result` แสดงว่าคำขอ API ได้รับการประมวลผลเรียบร้อยแล้ว

หากเกิดข้อผิดพลาด ให้ตรวจสอบ API Key, Endpoint, การตั้งค่าเครือข่าย และรูปแบบของคำขอ

## 7. ข้อควรระวังในการใช้ Alchemy API Key

หลังจากได้รับ API Key แล้ว สิ่งสำคัญคือการจัดเก็บและใช้งานอย่างปลอดภัย

### 7.1 อย่าเปิดเผย API Key ต่อสาธารณะ

อย่าใส่ API Key โดยตรงใน GitHub Repository สาธารณะ เอกสารที่เปิดเผยต่อสาธารณะ หรือ Client-side Code

หากเป็นไปได้ ควรใช้ Environment Variables หรือการตั้งค่าฝั่งเซิร์ฟเวอร์ (Server-side Settings) เพื่อจัดเก็บข้อมูลนี้อย่างปลอดภัย

### 7.2 ทำความเข้าใจความแตกต่างระหว่าง API Key และ Access Key

นอกจาก API Key แล้ว Alchemy ยังมีฟังก์ชันสำหรับจัดการ Access Key ด้วย

ทั้งสองอย่างอาจมีวัตถุประสงค์และวิธีจัดการที่แตกต่างกัน ดังนั้นควรตรวจสอบเอกสารทางการเพื่อเลือกวิธีการยืนยันตัวตนให้เหมาะสมกับโปรเจกต์ของคุณ

### 7.3 ใช้ Endpoint ให้ตรงกับเครือข่าย

เครือข่ายอย่าง Ethereum Mainnet และ Ethereum Sepolia มี Endpoint ที่แตกต่างกัน

ควรตรวจสอบให้แน่ใจว่าไม่ได้ใช้ Mainnet และ Testnet สลับกันโดยไม่ตั้งใจ

### 7.4 ตรวจสอบปริมาณการใช้งาน API และค่าใช้จ่าย

ควรตรวจสอบข้อมูลการใช้งานและค่าใช้จ่ายในบัญชี Alchemy เป็นประจำ

ปริมาณการใช้ API อาจแตกต่างกันตามขนาดของโปรเจกต์ ดังนั้นควรตรวจสอบราคาและข้อจำกัดการใช้งานที่มีผลกับบัญชีของคุณ

## 8. คำถามที่พบบ่อยเกี่ยวกับการสมัคร Alchemy และ API Key

### Q1: การสมัคร Alchemy ฟรีหรือไม่?

Alchemy มีแพ็กเกจฟรีสำหรับผู้เริ่มต้น แต่ฟีเจอร์บางอย่างและปริมาณการใช้งานอาจมีข้อจำกัด หากต้องการทราบราคาและขีดจำกัดล่าสุด โปรดตรวจสอบจากเว็บไซต์ทางการ

### Q2: หากหา API Key ไม่พบ ควรทำอย่างไร?

เข้าสู่ระบบ Alchemy Dashboard จากนั้นเปิดเมนู Apps และเลือกแอปที่ต้องการ คุณจะพบข้อมูล API Key และ Endpoints ในหน้ารายละเอียดแอป

### Q3: สามารถสร้าง API Key ได้หลายรายการหรือไม่?

ขึ้นอยู่กับวิธีจัดการแอปและโปรเจกต์ คุณสามารถจัดการแอปหลายรายการและข้อมูลการยืนยันตัวตน API ที่เกี่ยวข้องได้ โปรดตรวจสอบฟีเจอร์ที่รองรับจาก Dashboard และเอกสารทางการ

### Q4: สามารถแชร์ API Key ให้ผู้อื่นได้หรือไม่?

ไม่แนะนำให้แชร์ API Key ต่อสาธารณะ หากข้อมูลนี้ถูกเปิดเผย ผู้อื่นอาจนำไปใช้ส่งคำขอได้ ดังนั้นควรเก็บรักษาไว้ในที่ปลอดภัย

### Q5: ทำไม API Key ถึงใช้งานไม่ได้?

ลองตรวจสอบรายการต่อไปนี้

- API Key ถูกคัดลอกอย่างถูกต้องหรือไม่
- ที่อยู่ Endpoint ถูกต้องหรือไม่
- เลือกเครือข่ายบล็อกเชนถูกต้องหรือไม่
- รูปแบบคำขอ API ถูกต้องหรือไม่
- มีปัญหาเกี่ยวกับขีดจำกัดการใช้งานหรือสถานะของบริการหรือไม่

## 9. สรุป

Alchemy เป็นแพลตฟอร์มโครงสร้างพื้นฐานบล็อกเชนที่มีประโยชน์สำหรับนักพัฒนา Web3 โดยช่วยให้สามารถเชื่อมต่อกับเครือข่ายบล็อกเชนและเข้าถึงข้อมูลได้

ขั้นตอนทั้งหมดในการสร้างบัญชี Alchemy และรับ API Key มีดังนี้

1. เข้าเว็บไซต์ทางการของ Alchemy
2. สมัครสมาชิกด้วยอีเมลหรือวิธีเข้าสู่ระบบที่รองรับ
3. เข้าสู่ระบบ Dashboard
4. สร้างแอปใหม่จากเมนู Apps
5. เลือกเครือข่ายบล็อกเชนที่ต้องการ
6. คัดลอก API Key จากหน้ารายละเอียดแอป
