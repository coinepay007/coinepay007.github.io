## 一、ChatGPT Ads 是什么？

ChatGPT Ads 是 OpenAI 推出的广告服务，允许符合条件的企业和广告主在 ChatGPT 的使用场景中展示广告。

与传统搜索引擎广告不同，ChatGPT Ads 更注重用户的对话上下文。当用户通过 ChatGPT 查询信息、比较产品或寻找解决方案时，系统可以根据相关情境展示符合条件的广告。

例如：

- 用户咨询如何选择笔记本电脑，可能看到电脑品牌或电子产品相关广告。
- 用户寻找企业管理软件，可能看到相关 SaaS 产品广告。
- 用户讨论装修和家具购买，可能看到家居产品或相关服务广告。
- 用户计划海外旅行，可能看到旅游、酒店或出行服务相关广告。

对于企业而言，这种广告形式提供了新的营销机会，可以在用户探索需求和比较产品的过程中增加品牌曝光。

需要注意，ChatGPT Ads 广告与 ChatGPT AI 回答是相互独立的。广告需要明确标识，不应该影响 AI 的正常回答。

## 二、ChatGPT Ads 广告账户在哪里申请？

<badge color="success">OpenAI 官方入口</badge>

目前，企业可以通过 OpenAI Ads Manager 平台申请广告账户。

官方广告平台：

[https://ads.openai.com/](https://ads.openai.com/)

OpenAI 广告官方网站：

[https://openai.com/advertisers/](https://openai.com/advertisers/)

进入 Ads Manager 后，用户可以根据页面提示登录或注册 OpenAI 账户，并创建广告主账户。

广告账户创建后，可以在平台内完成广告活动设置、广告素材管理、预算配置、付款资料填写以及广告效果监测。

需要区分两个概念：

- **创建广告账户：** 注册并建立 Ads Manager 广告主账户。
- **获得广告投放资格：** 所在国家或地区、企业资料、账单设置以及广告审核等条件符合要求后，才能实际投放广告。

即使成功创建账户，也不代表广告可以立即展示。

## 三、ChatGPT Ads 开户需要满足什么条件？

在申请 ChatGPT Ads 之前，建议先了解平台的地区支持情况和账户要求。

### 1. 所在国家或地区必须支持

ChatGPT Ads 并不是所有国家和地区都可以直接进行自助开户。

OpenAI 会根据不同市场提供不同的广告账户接入方式，主要包括：

- Ads Manager 自助开户。
- 通过 OpenAI Ads 团队申请。
- 通过 OpenAI 授权的广告合作伙伴申请。

需要特别注意，自助开户资格与广告账户创建是两个不同概念。

根据 OpenAI 当前公布的规则，自助开户要求负责广告投放和付款的法律实体位于支持的国家或地区。如果所在地区暂时没有开放自助开户，可以先注册账户并等待平台通知，也可以了解是否有其他官方合作渠道。

查看最新国家和地区名单：

[https://help.openai.com/en/articles/20001245-ads-manager-availability](https://help.openai.com/en/articles/20001245-ads-manager-availability)

### 2. 准备 OpenAI 账户

申请人需要使用 OpenAI 账户登录 Ads Manager。

如果已经使用 ChatGPT，可以尝试使用现有 OpenAI 账户登录。

如果还没有账户，则需要先创建一个 OpenAI 账户。

建议使用企业日常管理的邮箱，方便后续管理广告账户、账单通知和团队权限。

### 3. 准备企业和品牌信息

创建广告账户时，需要填写广告主名称及其他必要信息。

建议提前准备：

- 企业或广告主名称。
- 品牌名称。
- 企业注册名称。
- 企业所在国家或地区。
- 企业账单地址。
- 账单联系人邮箱。
- 企业官方网站。
- 品牌 Logo。

其中，企业名称、品牌名称和法律实体名称具有不同用途，后续可以根据实际情况分别管理。

### 4. 准备付款方式

根据 OpenAI 当前的自助开户说明，采用信用卡账单方式的广告账户需要设置付款资料并添加信用卡。

通常需要准备：

- 可用于国际在线支付的信用卡。
- 与广告账户对应的账单地址。
- 企业名称及账单资料。
- 账单通知邮箱。

需要注意，付款方式是否被接受取决于 OpenAI 的支付规则、账户所在国家或地区以及发卡信息。

## 四、ChatGPT Ads 广告账户注册步骤

了解开户条件后，就可以开始申请广告账户。

### 第一步：打开 OpenAI Ads Manager

首先访问官方广告管理平台：

[https://ads.openai.com/](https://ads.openai.com/)

进入页面后，选择 Login 或 Sign up。

如果已经拥有 OpenAI 账户，可以直接登录；如果没有，则按照页面提示创建账户。

建议使用与企业业务相关的邮箱，便于后续统一管理。

### 第二步：选择开户方式

登录后，平台可能提供两种创建广告账户的方式。

**方式一：通过企业网站创建第一条广告**

如果页面要求输入网站地址，可以填写企业官方网站。

系统会根据网站信息辅助创建第一条广告。

随后可以：

1. 输入企业网站 URL。
2. 查看系统生成的广告内容。
3. 根据实际情况修改广告标题和描述。
4. 继续创建第一条广告活动。
5. 检查广告活动信息。
6. 填写广告主名称和其他必要账户资料。

提交后，广告需要经过审核。只有在广告审核、账单设置及其他账户条件满足后，才可能开始投放。

**方式二：跳过广告创建，直接进入 Ads Manager**

如果暂时不准备创建广告，也可以选择跳过网站广告创建步骤，直接进入 Ads Manager。

通常操作如下：

1. 打开注册页面。
2. 在网站地址填写步骤选择跳过。
3. 进入 Ads Manager。
4. 填写广告主名称及其他必要信息。
5. 创建广告主账户。
6. 后续再根据业务需求创建广告活动。

这种方式适合还在准备广告素材、预算和营销计划的企业。

### 第三步：填写广告主账户信息

创建账户时，需要认真填写广告主资料。

OpenAI 当前的账户设置说明涉及三个重要名称：

**Account Name（账户名称）**

账户名称主要用于 Ads Manager 内部识别和管理账户。

可以使用企业名称、项目名称或内部广告账户名称。

**Brand Name（品牌名称）**

品牌名称是与广告展示相关的公开品牌名称。

建议填写用户能够识别的品牌名称，并确保与企业实际经营的品牌保持一致。

**Legal Name（法律实体名称）**

法律实体名称用于账单和企业验证等用途。

建议填写企业正式注册名称，避免随意使用简称或其他不一致的名称。

在首次注册时，输入的广告主名称可能会作为这三个字段的初始值。

账户创建后，可以进入 Settings → General 分别调整。

需要注意，修改品牌名称或法律实体名称可能触发重新审核。

### 第四步：确认国家、货币和时区

这是开户过程中非常重要的一步。

创建广告账户时，平台可能要求确认：

- Country or Region：国家或地区。
- Currency：账单货币。
- Time Zone：账户时区。

提交之前一定要认真核对。

根据 OpenAI 当前的账户设置说明，广告账户创建后，国家或地区、账单货币和时区不能直接修改。

如果后续确实需要使用其他受支持的国家或货币设置，可能需要创建另一个广告账户，并重新完成相应的开户流程。

因此，不建议为了方便开户而随意填写国家或地区信息。

### 第五步：完成广告账户创建

确认账户资料后，按照页面提示提交。

如果信息填写完整，系统会创建广告主账户，并引导用户进入 Ads Manager。

进入后台后，可以查看账户信息、广告活动、账单设置和其他管理功能。

至此，广告账户的基础创建流程基本完成。

但要正式投放广告，还需要继续完成付款设置和相关审核。

## 五、ChatGPT Ads 付款方式如何设置？

广告账户创建完成后，需要进入账单设置页面完成付款资料配置。

对于自助信用卡账单账户，OpenAI 当前要求完成以下主要步骤。

### 1. 创建 Billing Profile

进入 Ads Manager 后，打开 Billing（账单）页面。

按照提示填写账单资料，通常包括：

- 企业名称。
- 企业账单地址。
- 账单联系人邮箱。
- 其他必要的账单信息。

如果采用发票账单安排，还可能需要填写 Billing Address 和 Purchaser Address。

其中：

- Billing Address：接收账单的企业地址。
- Purchaser Address：拥有广告账户并承担合同责任的法律实体地址。

两者可以相同，也可以根据实际企业安排填写不同地址。

### 2. 添加信用卡

完成账单资料后，根据页面提示添加付款方式。

自助信用卡账单账户需要填写：

- 信用卡信息。
- 持卡相关资料。
- 账单地址。

添加信用卡时，系统可能会进行临时预授权，以验证付款方式是否有效。

这类预授权不等于正式广告消费，通常会在验证后释放，但具体显示时间可能受到银行处理速度影响。

### 3. 注意信用卡国家与账单资料一致性

付款方式的国家或地区应与广告账户所使用的企业实体和账单资料相匹配。

例如，如果广告账户是以美国企业身份创建的，就应使用符合该账户要求的美国账单地址和付款方式。

如果使用来自其他国家或地区的卡片，可能无法通过付款验证。

因此，开户前应提前确认企业注册地、广告账户地区和付款方式之间的关系。

### 4. 了解广告费用的扣款方式

根据 OpenAI 当前公布的账单说明，ChatGPT Ads 采用后付费模式。

广告开始展示后，相关费用会逐步累计，并根据账户适用的账单安排进行扣款。

广告主需要在后台关注：

- 当前广告消费。
- 付款方式状态。
- 账户欠款情况。
- 账单记录。
- 广告预算使用情况。

不要将添加信用卡时出现的临时预授权误认为正式广告扣款。

## 六、开户后如何创建第一条 ChatGPT Ads 广告？

完成账户注册和账单设置后，就可以开始准备广告活动。

OpenAI Ads Manager 当前主要采用 Campaign、Ad Group 和 Ad 三层结构。

### 1. 创建 Campaign（广告活动）

Campaign 是广告活动的主要管理层级。

创建时通常需要设置：

- 广告活动名称。
- 广告目标。
- 广告预算。
- 投放时间。
- 相关投放条件。

根据实际业务需求选择合适的广告目标。

### 2. 创建 Ad Group（广告组）

广告组用于管理围绕特定主题或用户意图组织的广告。

在这一层级，可以根据业务需要设置相关的上下文提示（Context Hints），描述广告适合出现在哪些类型的对话场景中。

例如，一家销售企业软件的公司，可以围绕项目管理、团队协作和企业数字化等主题规划广告组。

### 3. 创建 Ad（广告素材）

广告素材是最终向用户展示的内容。

根据平台支持的格式，通常需要准备：

- 广告标题。
- 广告描述。
- 图片素材。
- 广告落地页 URL。

广告内容应该真实、清晰，并与落地页提供的信息保持一致。

不要使用虚假宣传、夸大效果或无法验证的承诺。

### 4. 提交广告审核

广告活动和素材完成后，需要提交审核。

OpenAI 会根据广告政策检查广告内容。

如果广告没有通过审核，可能需要根据后台提示修改素材或广告活动，再次提交。

只有广告审核通过，并且账户、付款和投放设置均符合要求后，广告才可能正式展示。

## 七、ChatGPT Ads 广告账户如何管理？

成功开户并开始投放后，还需要定期检查账户状态和广告效果。

### 1. 管理账户名称和品牌信息

进入：

Settings → General

可以查看和管理：

- Account Name。
- Brand Name。
- Legal Name。
- 品牌 Logo。

不同字段的修改可能触发不同审核流程。

例如，修改账户内部名称通常不会触发审核，而修改公开品牌名称或法律实体名称可能需要重新审核。

### 2. 邀请团队成员

如果企业有多人负责广告管理，可以通过以下入口邀请成员：

Settings → Users

根据实际工作需要，可以分配不同权限：

- **Admin：** 管理员，拥有完整平台权限。
- **Member：** 成员，可以创建和管理广告活动。
- **Viewer：** 查看者，只能查看相关内容。

建议由企业负责人或广告管理员创建主账户，再邀请其他团队成员加入，避免多人分别创建重复账户。

### 3. 监控广告数据

广告开始投放后，可以在 Ads Manager 中查看相关数据。

常见指标包括：

- Impressions：广告展示次数。
- Clicks：广告点击次数。
- Spend：广告消费金额。
- CTR：点击率。
- Average CPC：平均每次点击成本。
- Average CPM：平均千次展示成本。
- Conversions：转化次数（需要设置转化衡量）。

通过这些指标，可以了解广告是否获得足够曝光、用户是否愿意点击，以及广告预算是否得到有效利用。

## 八、ChatGPT Ads 开户常见问题

### 1. ChatGPT Ads 个人可以申请吗？

可以先通过 OpenAI Ads Manager 查看注册条件。

不过，ChatGPT Ads 是面向广告主的商业广告平台，开户过程中需要填写广告主信息、账单资料及相关企业信息。

是否能够使用个人身份完成申请，应以平台实际要求和所在地区的支持情况为准。

### 2. 中国大陆企业可以直接开户吗？

是否可以自助开户，需要查看 OpenAI 当前公布的国家和地区支持名单。

如果所在地区没有开放自助开户，不应使用虚假企业地址或不真实的注册资料绕过平台要求。

可以关注 OpenAI 官方后续公告，或了解适用的官方广告合作渠道。

### 3. 注册 OpenAI 账户后就能投放广告吗？

不一定。

创建 OpenAI 账户只是第一步，还需要创建广告主账户、完成账单设置、满足地区要求，并通过广告审核。

### 4. ChatGPT Ads 开户需要企业网站吗？

如果选择在注册过程中创建第一条广告，平台会要求提供网站 URL，以辅助生成广告内容。

如果暂时不准备创建广告，可以根据页面提供的选项跳过网站广告创建步骤，先进入 Ads Manager。

### 5. ChatGPT Ads 可以使用虚拟信用卡吗？

是否接受虚拟卡取决于 OpenAI 的付款规则、卡片类型、发行国家或地区以及广告账户的账单资料。

不能因为某张虚拟卡能够在其他海外网站付款，就认定它一定能够用于 ChatGPT Ads。

建议优先确认 Ads Manager 当前支持的付款方式，以及卡片和企业账单信息是否符合要求。

### 6. ChatGPT Ads 开户后多久可以投放？

账户创建成功不代表广告立即上线。

还需要完成账单设置、账户准备、广告内容审核和其他必要配置。

具体时间取决于账户状态和审核情况。

### 7. 可以修改广告账户的国家和货币吗？

根据 OpenAI 当前账户设置说明，广告账户创建后，国家或地区、账单货币和时区不能直接修改。

如果需要其他设置，可能需要创建新的广告账户，并重新完成开户流程。

### 8. 广告审核不通过怎么办？

可以进入 Ads Manager 查看广告状态和相关提示。

如果是广告内容或账户资料问题，可以根据平台要求修改后重新提交。

如果涉及企业验证或付款问题，则需要先完成对应的账户处理。

## 九、海外广告付款与数字服务支付工具

企业开始布局 ChatGPT Ads 等海外营销渠道后，除了广告账户本身，还需要考虑国际支付、数字服务订阅和区块链转账等不同场景。

不同工具对应不同用途，不应混淆。

### 1. CoinePay 虚拟卡平台

CoinePay 是一个虚拟卡平台，可为部分国际网站付款和数字服务订阅提供支付选择。

主要可以了解以下用途：

- 部分海外网站在线支付。
- 某些数字服务订阅付款。
- 国际在线消费管理。
- 不同线上支付场景的资金管理。
