## 1. ما هي Alchemy؟

Alchemy هي منصة توفر خدمات البنية التحتية لتطوير تطبيقات البلوك تشين. يمكن للمطورين استخدامها للاتصال بشبكات البلوك تشين، والحصول على البيانات، والتفاعل مع العقود الذكية (Smart Contracts).

تشمل أبرز ميزات Alchemy ما يلي:

- **خدمات RPC:** تساعد على إنشاء الاتصال بين التطبيقات وشبكات البلوك تشين.
- **الوصول إلى بيانات On-chain:** تتيح الحصول على بيانات المعاملات والكتل وغيرها من معلومات البلوك تشين.
- **أدوات المطورين:** تساعد في تطوير تطبيقات Web3 واختبارها وتصحيح أخطائها.
- **خدمات API:** توفر واجهات برمجية للاتصال بشبكات بلوك تشين مختلفة.

لبدء استخدام Alchemy، تحتاج أولاً إلى إنشاء حساب والحصول على API Key لاستخدامها في مشروعك.

## 2. ما الذي يجب تجهيزه قبل التسجيل في Alchemy؟

قبل البدء في عملية التسجيل، جهّز العناصر التالية.

### 2.1 عنوان بريد إلكتروني صالح

ستحتاج إلى عنوان بريد إلكتروني نشط لإنشاء حساب Alchemy وإكمال عملية التحقق من البريد الإلكتروني.

### 2.2 اتصال إنترنت مستقر

ستحتاج أثناء التسجيل إلى التحقق من البريد الإلكتروني وتسجيل الدخول إلى Dashboard، لذلك يُفضّل استخدام اتصال إنترنت مستقر.

### 2.3 تحديد شبكة البلوك تشين التي تريد استخدامها

قبل إنشاء API Key، حدد شبكة البلوك تشين التي ستستخدمها في مشروعك.

على سبيل المثال:

- Ethereum Mainnet
- Ethereum Sepolia
- Base

أثناء إنشاء التطبيق، يجب اختيار الشبكة المناسبة لاحتياجاتك.

## 3. إنشاء حساب على موقع Alchemy الرسمي

### 3.1 الدخول إلى الموقع الرسمي

انتقل إلى الموقع الرسمي لمنصة Alchemy:

[https://www.alchemy.com/](https://www.alchemy.com/)

في الصفحة الرئيسية، انقر على زر **Sign Up** أو **Sign In** أو **Get Started**.

### 3.2 إكمال عملية التسجيل

اتبع التعليمات الظاهرة على الشاشة. يمكنك إنشاء حساب باستخدام بريدك الإلكتروني أو استخدام إحدى طرق تسجيل الدخول عبر خدمات خارجية المدعومة.

إذا اخترت التسجيل باستخدام البريد الإلكتروني، فاتبع الخطوات التالية:

1. أدخل عنوان بريدك الإلكتروني.
2. أنشئ كلمة مرور أو اتبع التعليمات الأخرى الظاهرة على الشاشة.
3. افتح صندوق البريد الإلكتروني وابحث عن رسالة التحقق.
4. أكمل التحقق من البريد الإلكتروني ثم سجّل الدخول إلى حسابك.

### 3.3 الدخول إلى Dashboard

بعد إكمال تسجيل الدخول، افتح لوحة تحكم Alchemy:

[https://dashboard.alchemy.com/](https://dashboard.alchemy.com/)

تُعد Dashboard الواجهة الرئيسية لإدارة التطبيقات ومفاتيح API الخاصة بك.

قد تظهر في بعض الحسابات تطبيقات افتراضية أو API Key تم إنشاؤها مسبقًا بعد التسجيل. تحقق أولاً من المعلومات المتاحة، ثم أنشئ تطبيقًا جديدًا إذا كنت بحاجة إلى ذلك.

## 4. كيفية إنشاء تطبيق جديد في Alchemy

لإدارة API Key بطريقة منظمة، يُنصح بإنشاء تطبيق منفصل لكل مشروع عند الحاجة.

### 4.1 العثور على قائمة Apps

بعد تسجيل الدخول إلى Alchemy Dashboard، انتقل إلى القائمة التالية:

**Team Overview > Apps**

قد يختلف اسم القائمة أو موقعها قليلًا حسب إصدار واجهة الحساب.

### 4.2 النقر على Create new app

في صفحة Apps، انقر على زر **Create new app**.

ستظهر صفحة إنشاء تطبيق جديد، حيث يمكنك إدخال معلومات المشروع.

### 4.3 إدخال معلومات التطبيق

عادةً ما تتضمن الحقول التالية:

- **App Name:** اسم التطبيق أو المشروع.
- **Description:** وصف المشروع.
- **Chains:** شبكات البلوك تشين التي تريد استخدامها.
- **Services:** الخدمات أو الميزات المطلوبة.

على سبيل المثال، إذا كان مشروعك يعتمد على شبكة Ethereum، فاختر Ethereum ضمن خيار Chains.

### 4.4 إكمال إنشاء التطبيق

بعد إدخال جميع المعلومات المطلوبة، انقر على زر **Create App**.

بعد إنشاء التطبيق بنجاح، سيظهر ضمن قائمة Apps.

## 5. كيفية الحصول على Alchemy API Key

بعد إنشاء التطبيق، يمكنك الاطلاع على API Key الخاصة به.

### 5.1 فتح صفحة تفاصيل التطبيق

من قائمة Apps في Alchemy Dashboard، اختر التطبيق الذي أنشأته للتو.

ستجد في صفحة تفاصيل التطبيق المعلومات المتعلقة بواجهة API.

### 5.2 نسخ API Key

ابحث عن خيار **API Key** في صفحة تفاصيل التطبيق.

انقر على زر النسخ لنسخ API Key.

تُستخدم API Key كمعلومات للمصادقة حتى يتمكن تطبيقك من إرسال الطلبات إلى خدمات Alchemy. احرص على عدم كشفها للآخرين.

### 5.3 الاطلاع على Endpoints

يمكنك أيضًا الانتقال إلى علامة التبويب **Endpoints** في صفحة تفاصيل التطبيق للاطلاع على عناوين API الخاصة بالشبكات المختلفة.

مثال على Ethereum Mainnet RPC Endpoint:

```
https://eth-mainnet.g.alchemy.com/v2/YOUR_API_KEY
```

استبدل `YOUR_API_KEY` بمفتاح API الحقيقي الذي حصلت عليه.

تجدر الإشارة إلى أن TRXAPI خدمة مستقلة مرتبطة بتأجير طاقة شبكة TRON، ولا توجد لها علاقة بـ Ethereum RPC Endpoint الخاص بمنصة Alchemy.

## 6. اختبار ما إذا كانت API Key تعمل بشكل صحيح

بعد نسخ API Key، يمكنك إرسال طلب API فعلي للتحقق من أنها تعمل بصورة صحيحة.

### 6.1 تشغيل أمر الاختبار

افتح Terminal أو أداة Command Line، ثم نفّذ الأمر التالي.

استبدل `YOUR_API_KEY` بمفتاح API الحقيقي الخاص بك.

```
curl https://eth-mainnet.g.alchemy.com/v2/YOUR_API_KEY \
-X POST \
-H "Content-Type: application/json" \
-d '{"jsonrpc":"2.0","method":"eth_blockNumber","params":[],"id":1}'
```

### 6.2 التحقق من الاستجابة

إذا تمت معالجة الطلب بنجاح، فقد تحصل على استجابة JSON مشابهة لما يلي:

```
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": "0x..."
}
```

إذا ظهر رقم الكتلة في حقل `result`، فهذا يعني أن طلب API تمت معالجته بنجاح.

أما إذا ظهرت رسالة خطأ، فتحقق من API Key وعنوان Endpoint وإعدادات الشبكة وتنسيق الطلب.

## 7. احتياطات مهمة عند استخدام Alchemy API Key

بعد الحصول على API Key، من المهم الحفاظ عليها آمنة.

### 7.1 لا تنشر API Key للعامة

لا تضع API Key مباشرة في مستودعات GitHub العامة أو المستندات المتاحة للجميع أو داخل Client-side Code.

حاول استخدام Environment Variables أو إعدادات Server-side لحفظها بطريقة أكثر أمانًا.

### 7.2 فهم الفرق بين API Key وAccess Key

توفر Alchemy، بالإضافة إلى API Key، ميزات لإدارة Access Key أيضًا.

قد تختلف طريقة استخدام وإدارة كل منهما، لذلك راجع الوثائق الرسمية لاختيار طريقة المصادقة المناسبة لاحتياجات مشروعك.

### 7.3 استخدام Endpoint الخاص بالشبكة الصحيحة

تختلف عناوين Endpoints بين شبكات مثل Ethereum Mainnet وEthereum Sepolia.

تأكد من عدم استخدام Mainnet وTestnet بدلًا من بعضهما عن طريق الخطأ.

### 7.4 متابعة استخدام API والتكاليف

تحقق بانتظام من معلومات الاستخدام والرسوم المتعلقة بحساب Alchemy الخاص بك.

قد يختلف حجم استخدام API حسب طبيعة المشروع وحجمه، لذلك تأكد من معرفة الأسعار وحدود الاستخدام المطبقة على حسابك.

## 8. الأسئلة الشائعة حول التسجيل في Alchemy وAPI Key

### Q1: هل إنشاء حساب Alchemy مجاني؟

توفر Alchemy خطة مجانية للمستخدمين الجدد، ولكن قد تكون هناك قيود على بعض الميزات وحجم الاستخدام. للاطلاع على أحدث الأسعار وحدود الاستخدام، راجع الموقع الرسمي.

### Q2: ماذا أفعل إذا لم أتمكن من العثور على API Key؟

سجّل الدخول إلى Alchemy Dashboard، ثم افتح قائمة Apps واختر التطبيق المطلوب. ستجد معلومات API Key وEndpoints في صفحة تفاصيل التطبيق.

### Q3: هل يمكن إنشاء أكثر من API Key؟

وفقًا لطريقة إدارة التطبيقات والمشاريع، يمكنك إدارة تطبيقات متعددة ومعلومات المصادقة المرتبطة بها. لمعرفة الميزات المتاحة، راجع Dashboard والوثائق الرسمية.

### Q4: هل يمكن مشاركة API Key مع أشخاص آخرين؟

لا يُنصح بمشاركة API Key بشكل علني. إذا تم كشفها، فقد يتمكن الآخرون من استخدامها لإرسال الطلبات. لذلك احرص على تخزينها في مكان آمن.

### Q5: لماذا لا تعمل API Key؟

تحقق من الأمور التالية:

- التأكد من نسخ API Key بشكل صحيح.
- التأكد من صحة عنوان Endpoint.
- التأكد من اختيار شبكة البلوك تشين الصحيحة.
- التأكد من صحة تنسيق طلب API.
- التحقق من حدود الاستخدام أو حالة الخدمة في حسابك.
