## 1. Czym jest Alchemy?

Alchemy to platforma infrastruktury blockchain, która pomaga programistom łączyć aplikacje z różnymi sieciami blockchain bez konieczności samodzielnego tworzenia i utrzymywania węzłów.

Dzięki Alchemy programiści mogą:

- Łączyć się z obsługiwanymi sieciami blockchain.
- Uzyskiwać dostęp do danych blockchain za pomocą API RPC.
- Sprawdzać informacje o portfelach i transakcjach.
- Pobierać dane związane z NFT.
- Monitorować aktywność i transakcje blockchain.
- Tworzyć i rozwijać aplikacje Web3.

Dla początkujących Alchemy upraszcza tworzenie aplikacji blockchain, zapewniając gotową infrastrukturę i usługi API.

## 3. Jak zarejestrować konto w Alchemy?

[https://www.alchemy.com/](https://www.alchemy.com/)

W zależności od dostępnych opcji możesz zarejestrować się za pomocą adresu e-mail lub skorzystać z obsługiwanej metody logowania zewnętrznego.

Jeśli wybierasz rejestrację przez e-mail:

1. Wprowadź swój adres e-mail.
2. Uzupełnij wymagane informacje dotyczące konta.
3. Postępuj zgodnie z instrukcjami, aby zweryfikować adres e-mail lub przejść dodatkowe kontrole bezpieczeństwa.
4. Po zakończeniu rejestracji zaloguj się na swoje konto.

Dostępne metody rejestracji i wymagania dotyczące weryfikacji mogą się zmieniać. Zawsze postępuj zgodnie z instrukcjami na oficjalnej stronie Alchemy.

[https://dashboard.alchemy.com/](https://dashboard.alchemy.com/)

Przed utworzeniem nowej aplikacji sprawdź, czy na koncie istnieją już dostępne aplikacje. Być może możesz od razu skorzystać z domyślnej konfiguracji.

Aplikacja Alchemy łączy Twój projekt z wybranymi sieciami blockchain i udostępnia dane uwierzytelniające oraz endpointy potrzebne do wysyłania żądań.

## 5. Jak uzyskać API Key w Alchemy?

API Key służy do uwierzytelniania żądań wysyłanych do usług Alchemy powiązanych z Twoją aplikacją.

Wykonaj poniższe kroki, aby znaleźć swój klucz.

### Krok 1: Otwórz aplikację

Przejdź do sekcji Apps w Alchemy Dashboard.

Znajdź utworzoną aplikację i kliknij jej nazwę, aby otworzyć stronę szczegółów.

### Krok 2: Skopiuj API Key

Na stronie szczegółów aplikacji znajdź API Key, który zazwyczaj jest wyświetlany w górnej prawej części ekranu.

Kliknij przycisk kopiowania, aby skopiować klucz.

Zapisz go w bezpiecznym miejscu, aby móc wykorzystać go w swoim projekcie programistycznym.

Nie publikuj prawdziwego API Key na publicznych stronach internetowych, w publicznych repozytoriach GitHub ani w innych miejscach, do których mogą uzyskać dostęp nieuprawnione osoby.

### Krok 3: Znajdź API Endpoint

Po uzyskaniu API Key otwórz zakładkę Endpoints na stronie szczegółów aplikacji.

W tej sekcji znajdziesz endpointy HTTP i WebSocket dla włączonych sieci blockchain.

Przykładowy endpoint HTTP RPC dla Ethereum Mainnet zazwyczaj wygląda następująco:

[https://eth-mainnet.g.alchemy.com/v2/YOUR_API_KEY](https://eth-mainnet.g.alchemy.com/v2/YOUR_API_KEY)

Zastąp YOUR_API_KEY kluczem skopiowanym z Alchemy Dashboard.

Każda sieć blockchain ma inny adres endpointu. Zawsze korzystaj z adresu odpowiadającego wybranej sieci.

## 6. Jak sprawdzić, czy API Key Alchemy działa?

Po uzyskaniu API Key warto wysłać proste żądanie, aby sprawdzić, czy konfiguracja jest prawidłowa.

W tym przykładzie wykorzystamy Ethereum Mainnet oraz metodę JSON-RPC eth_blockNumber do pobrania numeru najnowszego bloku.

### Krok 1: Przygotuj RPC Endpoint

Użyj następującego formatu:

[https://eth-mainnet.g.alchemy.com/v2/YOUR_API_KEY](https://eth-mainnet.g.alchemy.com/v2/YOUR_API_KEY)

Zastąp YOUR_API_KEY swoim prawdziwym kluczem API.

### Krok 2: Wyślij żądanie za pomocą curl

Jeśli curl jest dostępny na Twoim komputerze, otwórz terminal i wykonaj poniższe polecenie:

```
curl https://eth-mainnet.g.alchemy.com/v2/YOUR_API_KEY \
-X POST \
-H "Content-Type: application/json" \
-d '{"jsonrpc":"2.0","method":"eth_blockNumber","params":[],"id":1}'
```

Pamiętaj, aby przed wykonaniem polecenia zastąpić YOUR_API_KEY swoim prawdziwym kluczem.

### Krok 3: Sprawdź odpowiedź

Jeśli API Key i endpoint zostały skonfigurowane prawidłowo, otrzymasz odpowiedź JSON podobną do poniższej:

```
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": "0x..."
}
```

Pole result zawiera numer bloku zapisany w formacie szesnastkowym.

Jeśli żądanie zwróci błąd, sprawdź, czy API Key jest prawidłowy, odpowiednia sieć została włączona i format żądania jest poprawny.

## 7. Ważne wskazówki dotyczące bezpieczeństwa API Key

API Key jest ważnym poświadczeniem umożliwiającym dostęp do usług Alchemy. Stosuj poniższe zasady, aby chronić swoje konto i aplikacje.

### Nie publikuj swojego API Key

Nigdy nie udostępniaj prawdziwego API Key w publicznych repozytoriach kodu, na forach internetowych ani na publicznie dostępnych stronach.

W projektach programistycznych warto przechowywać klucz w zmiennych środowiskowych lub bezpiecznych plikach konfiguracyjnych.

### Poznaj różnicę między API Keys a Access Keys

Alchemy oferuje różne rodzaje poświadczeń przeznaczonych do różnych zastosowań.

API Key aplikacji jest zwykle używany do uzyskiwania dostępu do endpointów RPC i obsługiwanych interfejsów API powiązanych z aplikacją.

Access Keys są wykorzystywane w określonych scenariuszach uwierzytelniania i zarządzania. Mogą również zapewniać dodatkowe mechanizmy kontroli uprawnień.

Nie zakładaj, że te poświadczenia można stosować zamiennie. Przed użyciem sprawdź oficjalną dokumentację Alchemy.

### Wybierz właściwą sieć blockchain

Upewnij się, że aplikacja jest skonfigurowana dla sieci, z której rzeczywiście chcesz korzystać.

Na przykład:

- Ethereum Mainnet jest wykorzystywana w produkcyjnej sieci Ethereum.
- Ethereum Sepolia służy do testów.
- Base jest odrębną siecią blockchain.

Użycie endpointu należącego do niewłaściwej sieci może prowadzić do nieoczekiwanych wyników lub błędów.

### Monitoruj wykorzystanie i ceny

Alchemy oferuje różne plany korzystania z usług. Dostępne funkcje, limity i ceny mogą ulegać zmianom.

Przed wykorzystaniem Alchemy w aplikacji produkcyjnej sprawdź aktualny plan, limity wykorzystania i informacje dotyczące rozliczeń w Dashboard.

Pamiętaj również, że inne usługi związane z blockchain mogą pełnić zupełnie inne funkcje. Na przykład TRXAPI koncentruje się na wynajmie energii TRON, natomiast Alchemy dostarcza infrastrukturę do tworzenia aplikacji blockchain.

Możesz tworzyć kilka aplikacji dla różnych projektów lub środowisk programistycznych i zarządzać ich poświadczeniami oddzielnie.

Nie zaleca się niepotrzebnego udostępniania klucza.

Jeśli inni programiści potrzebują dostępu do Twoich usług Alchemy, korzystaj z odpowiednich uprawnień zespołu i bezpiecznych metod zarządzania poświadczeniami.

Nie publikuj osobistych ani projektowych danych dostępowych w miejscach publicznych.

### Q5: Dlaczego mój API Key Alchemy nie działa?

Najczęstsze przyczyny to:

1. API Key został nieprawidłowo skopiowany.
2. Adres endpointu RPC jest nieprawidłowy.
3. Wymagana sieć blockchain nie została włączona.
4. Metoda lub parametry żądania są nieprawidłowe.
5. Aplikacja ma ograniczenia dotyczące wykorzystania usług lub uprawnień.
6. Występuje problem z połączeniem internetowym.

Najpierw sprawdź ustawienia aplikacji i konfigurację endpointu. Możesz również skorzystać z oficjalnej dokumentacji Alchemy, aby znaleźć instrukcje rozwiązywania problemów.
